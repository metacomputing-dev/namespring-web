# Copy Style Guide (FE 요약)

이 문서는 `lib/spring-ts/docs/NARRATIVE_STYLE_GUIDE.md` 의 FE 친화 요약이다. FE 개발자 / QA / 카피 운영자가 새 카드를 디자인할 때 빠르게 참고할 수 있도록 한다.

원전 (편집 권한): `lib/spring-ts/docs/NARRATIVE_STYLE_GUIDE.md`. 이 문서와 충돌이 있으면 원전이 우선이다.

---

## 1. 한 줄 정리

- **brief** (≤ 28자, 1~2 문장): 첫 화면. 어렵지 않게.
- **standard** (3~7 문단): 펼친 뒤 일반 사용자용. 비유 1개 일관, 생활 팁 / 주의점 포함.
- **expert** (4~8 문단 + tag chip): "전문가 근거" 버튼 이후. `#태그` 와 `numericalEvidence` 사용.

---

## 2. 종결어 / 호칭 / 금지어 (모든 depth 공통)

| 항목 | 규칙 |
|---|---|
| 종결어 | `~해요` / `~에요` / `~이에요`. `~다` / `~한다` 금지 (expert 의 고전 인용 예외). |
| 호칭 | `당신은` 금지. 행위·상태로 풀어 쓴다 (`이 흐름에서 가장 단단해지는 자리예요`). |
| 명령형 | 본문 금지. `livingTips` 안에서만 `~하세요` 허용. |
| 단정 어조 | `반드시`, `~이다` 금지. 권유·약한 확신: `~인 편이에요`, `~경향이 있어요`. |
| 불안 자극 | `큰일`, `위험`, `불행` 금지. 대안: `천천히 살피면 좋아요`, `무리만 줄이면 충분해요`. |

## 3. depth 별 contract

### 3-1. brief

| 필드 | 규칙 |
|---|---|
| `headline` | ≤ **28 한글 자모**. 한 줄. (Phase 3 에서 후처리 압축으로 invariant 0 위반.) |
| `hook` | 옵셔널. 보조 1 문장. |
| 비유 | 가능. 어려운 한자어 금지. |
| 별점 | 본문에서 직접 언급 금지. `stars` 필드만 사용. |

예: `"올해는 재물 흐름이 단단해요."`

### 3-2. standard

| 필드 | 규칙 |
|---|---|
| `paragraphs[].plainText` | 3 ~ 7 문단. 한 문단 80 ~ 160 자. |
| 권장 구조 | (1) 큰 그림 (2) 비유 (3) 강점 (4) 주의점 (5) 마무리 격려. |
| `livingTips` | 1 ~ 3개. 각 ≤ 24자. 동사 격언풍. |
| `cautions` | 0 ~ 2개. 약한 어조 (`~만 줄이면 충분해요`). |
| 인라인 태그 | **없음**. 한자어는 한글 풀이로 (`정관` → `책임을 받는 자리`). |

### 3-3. expert

| 필드 | 규칙 |
|---|---|
| 어휘 | 격국·용신·십성·조후 가능. |
| 인라인 `#태그` | 문단당 2 ~ 6개. 30자당 ≤ 1개. |
| `numericalEvidence` | 수치 인용은 반드시 이 필드로. 본문에 임의 숫자 금지. |
| 톤 (`axisStrength.hedge`) | `definite` → `~격이 분명해요` / `practical` → `~격으로 보여요` / `candidate` → `~격에 가까운 모양이에요` / `deferred` → `~격일 수도 있어 추가 단서가 필요해요`. |

`#태그` 클릭 시 glossary panel 호출 (`tieredMatrix.glossary.entries[<tagId>]`).

## 4. 비유 사용 (오행 → 식물·날씨·도구·악기)

한 fragment 안에서 **비유 1개를 일관되게**. 다른 element 와 섞지 않는다.

| 오행 | 정체성 | 일상 비유 |
|---|---|---|
| 木 (나무) | 자라는, 위로 뻗는 | 새싹, 봄비 맞은 가지, 자라는 화분, 곧게 뻗은 줄기 |
| 火 (불) | 빛나는, 따뜻한 | 등불, 모닥불, 한낮의 햇살, 깜빡이는 별 |
| 土 (흙) | 단단한, 받쳐 주는 | 들판, 어깨를 기댈 언덕, 잘 다진 흙, 햇살 든 마루 |
| 金 (쇠) | 다듬는, 결단하는 | 잘 만든 도구, 가을바람, 정확한 자, 종소리 |
| 水 (물) | 흐르는, 깊은 | 우물, 강물, 호수, 스며드는 빗물 |

추가 anchor: `lib/spring-ts/data/narrative/_metaphor/<element>.json`. 5 element × 18 anchor = 90 anchor. 시기·시간대·age band conditional 사용 가능.

## 5. 성별 modifier

| 차원 | 권장 | 회피 |
|---|---|---|
| 가족 | `중심을 잡는`, `따뜻하게 챙기는` | `가장으로서`, `엄마/딸로서` (선입견) |
| 직업 | 자리·책임·표현으로 풀어 쓰기 | 단정적 직업명 (`의사`, `교사`) |
| 연애 | `짝`, `인연` | `이성`, `남친/여친` 단정 |

원칙: **성별로 가능성 좁히지 않기**. 성별 차이는 표면 어휘만 (가족 안 호칭 정도).

## 6. 연령대 modifier

| 연령대 | 핵심 톤 |
|---|---|
| 0-9 | 보호자 함께 읽는 가정. 3인칭 (`아이는`). 행동 위주. 진로·연애 미언급. |
| 10-19 | 친구 같은 어조. 학업·관계 비중. 직업·결혼 단정 금지. |
| 20-29 | 도전·시작. 현실적 첫 결정. 선택지 제시형. |
| 30-39 | 균형·확장. 가족·일·자기 사이의 조정. |
| 40-54 | 단단함·재정비. 책임 큰 자리. 건강 신호 시작. |
| 55-69 | 정리·전환. 후반기 흐름. 다음 세대 언급 가능. |
| 70+ | 풍요·여유. 결실. 건강은 따뜻하게. 무리·초조 어휘 회피. |

## 7. 카테고리 voice

| 카테고리 | voice 한 줄 |
|---|---|
| `overall` | 큰 그림, 격려, 종합. |
| `wealth` | 재물·관리·기회. **두려움 자극 X**. |
| `health` | 따뜻함, 일상 팁 비중. **의학 단정 X**. |
| `academic` | 시험·시기. 무리·압박 X. |
| `romance` | 인연·관계. **결혼 단정 X**. |
| `family` | 가까운 사람·뿌리. 비교 X. |
| `career` | 자리·책임. **직장 폄하 X**. |
| `study_document` | 시험·자격·서류. 합격 단정 X. |
| `expression_children` | 표현·자녀. **무자녀 단정·강요 X**. |
| `health_stress` | 스트레스·휴식. 진단·약 단정 X. |
| `movement` | 이동·변화. 거주지·국적 단정 X. |

## 8. 절대 금기

- 의학·법률·재무 직접 처방 (`먹어야 한다`, `소송하라`, `~주식 사라`).
- 사망·이별 시기 단정 (`~년에 헤어진다` 등).
- 종교 권유.
- 다른 사람 흉보는 어조.
- 사주 외 다른 점술 (타로·관상 등) 단정.

## 9. 사례 (good vs bad)

| good | bad |
|---|---|
| 올해는 재물 흐름이 단단해요. | 올해 재물운 5점, 큰돈이 들어와요! |
| 새싹이 햇빛을 향해 자라듯 표현이 또렷해지는 시기예요. | 당신은 마치 거센 폭풍 같은 격동의 시기를 맞이할 것입니다. |
| 한 박자 쉬어 가면 좋아요. | 절대 무리하지 말고 즉시 휴식을 취해야 합니다. |
| 가까운 사람과의 결이 부드럽게 닿는 자리예요. | 당신의 부인/남편은 ~할 것이며, 자녀는 ~합니다. |
| 가을바람처럼 마무리할 일이 또렷해져요. | 가을이 되면 모든 일이 잘 풀릴 것이 명백합니다. |
| 작은 기록이 다음 결정을 도와줘요. | 매일 일기를 반드시 써야 운이 들어옵니다. |

## 10. 작성 / 검수 self-check (FE QA 도 활용)

- [ ] depth contract 부합 (brief 1~2문장, standard 3~7문단, expert 4~8문단).
- [ ] 종결어 `~해요`체 일관.
- [ ] 비유 1개 일관 (한 fragment 안에서 element 섞지 않음).
- [ ] 성별·연령대 modifier 적용.
- [ ] 절대 금기 어구 0개.
- [ ] expert tier 만 `#태그` 사용, `glossary.entries` 에 모두 존재.
- [ ] livingTips / cautions 길이 ≤ 24자.
- [ ] brief headline ≤ 28자 (Phase 3 후처리 invariant. 위반 시 엔진이 자동 압축).

## 11. FE 수신 측에서 주의

- `tieredMatrix.glossary.entries[<id>].brief` 가 1차 노출 텍스트, `detailed` 가 "자세히" 클릭 후 노출.
- 모든 glossary entry 는 `aiGenerated: true`, `sourceTier.tier: T1_HYPOTHESIS`. 권위 인용으로 사용 금지 (FE 에서 "정의" 라벨 정도가 안전).
- expert paragraph 의 `tokens[]` 안 `kind: 'hashtag'` 토큰만 chip 으로 렌더. 다른 kind (`text`, `boldText` 등) 는 plain text.
- `fortuneCascadeMode`, `surfacePalace`, `surfaceNaeum` 같은 declared opt-in 은 현재 추가 surface 없을 수도 있다 (saju-ts 측 포팅 대기). top-level 키 변화로만 활용 여부 확인 가능.
