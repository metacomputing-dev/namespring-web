# P40 유료 UI 실제 출력 샘플

이 파일들은 `precisionConfig.surfaceTieredMatrix=true`로 생성한 실제 `tieredMatrix` 고객 노출 텍스트입니다.
내부 QA용 fragment id/selection seed는 제외했고, 고객 화면에서 보일 수 있는 요약, 일반 해설, 전문가 근거, 수치 근거, 태그 풀이, 이름 수리 근거를 담았습니다.
