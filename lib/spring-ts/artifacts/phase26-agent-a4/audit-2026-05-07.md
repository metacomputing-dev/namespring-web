## Methodology

1. P25-A5 audit identified the gap (34 distinct hooks across 32
   fixtures, max=15 concentration). Recommendation #6 frames the
   target as 34 → ~50.
2. Distinct hook expansion needs each new fragment to satisfy:
   (a) text uniqueness against the 34 existing hooks,
   (b) selector specificity high enough to beat the existing
   max-specificity winner in the target slot for at least one fixture,
   (c) hook ≤24 Korean code points after `normalizeRenderedText`,
   (d) cumulative concentration projection ≤18 (audit-permitted margin).
3. Per-slot specificity ceilings were measured by enumerating
   `cell.selectedFragments.brief.gating` across the 32 fixtures'
   tiered matrices (32 × 11 cat × 5 period sweep). Slots whose
   ceiling was 1 or 2 dims received 2- or 3-dim gating respectively.
4. Concentration projection per fixture was simulated by computing
   gender × ageBand × dayMasterStrength feature triples per fixture
   (gender + ageBand from `request.birth`, dayMasterStrength inferred
   from majority-allow value across selectedFragments) and counting
   how many planned fragments would fire on each fixture.
5. After authoring, `npm run samples:regen` regenerated the 36
   `*-tiered.json` artifacts (and `index.json`) from the freshly-built
   `saju-ts` dist; `ci:hook-coverage` confirmed 42 / 42 / 0 / 0
   (authored / distinct / dormant slot / dormant text).
6. `ci:hook-concentration` confirmed max moved 15 → 16 (margin 4 vs
   threshold 20). `ci:samples-stale` PASS (0 violations).
7. `test:namespring-compat` 202 / 0 PASS held.
