## Root cause

All 11 cells trace to a single fragment, selected by gating
`STRONG | EXTREME_STRONG`-strength × `neutral` yongshin × `20-29 / 30-39 /
40-54 / 55-69 / 70+` ageBand:

- Fragment ID: `romance.thisMonth.brief.strong.neutral.adult.001`
- Source text: `이번 달은 사람과의 결이 차분히 정돈되는 흐름이에요.` (29 chars)

Pipeline trace:
1. `normalizeRenderedText` → `reduceOverusedGyeol` substitutes the source's
   single `결이` to `흐름이` (paragraph budget unused). Intermediate:
   `이번 달은 사람과의 흐름이 차분히 정돈되는 흐름이에요.` (30 chars).
2. `compressBriefHeadlineIfApplicable` (30 ∈ [29..32]) reverses the trailing
   `흐름이에요` → `결이에요`. Result: `이번 달은 사람과의 흐름이 차분히
   정돈되는 결이에요.` (29 chars). The cluster guard correctly blocks the
   second `흐름이 → 결이` reversal that would form the doubled `결이 ... 결이에요`.

The simulation against current-main `src/report/tiered/template-engine.ts`
(commit `a2d35e9` HEAD `c4e65aa`) confirms the cluster guard works as
intended. The 11 cells in `pre-fix-snapshot-2026-05-07.json` reflect
**stale samples**: the `samples-stale` regen-drift cycle re-opened by the
P18-A3 standard-fragment regen (`52f8cef`) overwrote the safe headline
captured by P18-A4's regen (`c75d211`).

## Fix

Replace the source's first `결이` with `리듬이`. The choice avoids the
post-processor reversal cycle entirely because `리듬이` is NOT a member
of `BRIEF_HEADLINE_REVERSALS`. This is robust against any future
divergence of the cluster-guard semantics in src.

### Before

```json
{ "kind": "text", "value": "이번 달은 사람과의 결이 차분히 정돈되는 흐름이에요." }
```

### After

```json
{ "kind": "text", "value": "이번 달은 사람과의 리듬이 차분히 정돈되는 흐름이에요." }
```

### Pipeline output (post-fix simulation)

- Source: 30 chars (`사람과의 리듬이 차분히 정돈되는 흐름이에요`).
- After `normalizeRenderedText`: unchanged (30 chars). `리듬이` is not a
  rewrite target.
- After `compressBriefHeadlineIfApplicable`: `이번 달은 사람과의 리듬이
  차분히 정돈되는 결이에요.` (29 chars). Single `결X` form — doubled
  cluster check passes.

Length 29 chars > 28 invariant hint, but `compressBriefHeadline` is
best-effort and accepts >28 when no safe reversal applies. The
`tiered-brief-headline-invariant.test.ts` 40 / 40 PASS (no fragment in
its inflated samples list overlaps this one).
