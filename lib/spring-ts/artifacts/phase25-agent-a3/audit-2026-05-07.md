## Discriminator framework

For each fragment, "narrow is intent" requires that **at least one** of:

A. Hook/template prose itself encodes the cohort (voice would not fit
   if relaxed).
B. The bundle uses cohort-partition design (one fragment per cohort,
   each with its own template — broadening one breaks the partition).
C. The gating dimension is **selection-mechanics-load-bearing** —
   relaxing it changes which competing fragment wins for a non-trivial
   reader population (specificity score change at relax level 0).
D. P21-A4 already adjudicated this fragment.

Holds anchored to (C) are the strongest, because the gate is doing
real work in fragment-selector.ts at strict match time.

### 1. `family.today.brief.young.003` — hold (A + B)

### 2. `health.today.brief.strong.elder.001` — hold (C, strongest case)

| Property | Value |
|---|---|
| gating | `ageBand=["70+"]`, `dayMasterStrength=["STRONG","EXTREME_STRONG"]` |
| template | "오늘은 한 박자 천천히 가는 흐름이 잘 맞아요." |
| hook | "물 한 잔과 가벼운 산책이 도움돼요." |
| competing siblings (same `cat\|period`) | wild.002 (no gate), strong.001 (strength only), weak.001, balanced.001, aligned.001, neutral.001 (HAS hook), conflicting.001, child.001 |

**Discriminator C (selection-mechanics-load-bearing)**: This is the
load-bearing case in the tail. `fragment-selector.ts` orders relaxation
as `gender → agePhase → ageBand → currentSeason → birthSeason → dayMasterPolarity → dayMasterStrength → yongshinAlignment → ...` (FALLBACK_DIMENSIONS).
At relax level 0 (no relaxation, strictest match), specificity score
counts non-empty gating dimensions. For a reader who is 70+ STRONG (or
EXTREME_STRONG):

| Candidate | gating dims set | specificity at level 0 | matches? |
|---|---|---|---|
| `strong.elder.001` | ageBand, dayMasterStrength | 2 | ✓ |
| `strong.001` | dayMasterStrength | 1 | ✓ |
| `wild.002` | — | 0 | ✓ |
| `neutral.001` (yongshin neutral 70+ STRONG) | yongshinAlignment | 1 | ✓ if yongshin neutral |

`strong.elder.001` dominates `strong.001` (specificity 2 > 1) and
dominates `neutral.001` (2 > 1) for STRONG ELDER NEUTRAL readers — so
it wins deterministically when reader is 70+ STRONG.

**If the strength gate were dropped** (so `strong.elder.001` keeps only
`ageBand=["70+"]`):
- vs `strong.001`: tie at specificity 1 → seed-based hash pick (50 %
  chance regression for STRONG ELDER cells).
- vs `neutral.001` (yongshin neutral): tie at 1 → 50 % regression.
- vs `aligned.001`/`conflicting.001`: ties for 70+ ALIGNED / CONFLICTING.

So dropping `dayMasterStrength` from this fragment converts a
deterministic dominance into a coin flip across 4 readers categories
(STRONG, ALIGNED, NEUTRAL, CONFLICTING — separate from the BALANCED
elder case which currently has no elder-specific fragment at all).

**Voice/tone independence does NOT imply gate is removable.** The hook
"물 한 잔과 가벼운 산책" is voice-neutral across yongshin/strength, but
the *gate* is doing structural work in selection that voice-only
analysis misses.

**Verdict**: Hold. Strongest single rationale in the tail. Authoring
intent is encoded in the gate as a tie-breaker for the 70+ cohort.

## Fragment-selector specificity primer (for future agents)

`src/report/tiered/fragment-selector.ts` implements:

```
for (let relaxBefore = 0; relaxBefore <= FALLBACK_DIMENSIONS.length; relaxBefore++) {
  matched = candidates.filter(fragmentMatchesUntil(_, _, relaxBefore));
  if (matched.length === 0) continue;
  maxSpec = max(matched.map(f => specificityScore(f, relaxBefore)));
  scoped = matched.filter(f => specificityScore(f, relaxBefore) === maxSpec);
  return scoped[seedHash % scoped.length];
}
```

Two fragments with the same specificity at the matching relax level
are tie-broken by FNV-1a hash of `(birth + targetDate + axis)`. So
fragmentA (specificity 2) > fragmentB (specificity 1) at any given
relax level is *deterministic*; same specificity is a coin-flip per
selection seed.

This is why `health.today.brief.strong.elder.001`'s 2D gate is
load-bearing: dropping `dayMasterStrength` collapses the 2-1 dominance
to a 1-1 tie with multiple siblings, regressing the elder voice for
~50 % of STRONG-ELDER cells per seed.
