## Paraphrase rationale

Choice: `연결입니다` → `연결고리입니다`.

Rationale:

1. **Adjacent `_coverage/` cells already use `연결고리`.** P18-A5's data
   rephrase pattern across `age-band-mature-senior-gender-pairs:235`,
   `age-phase-axis:470`, `age-phase-expert-mature:673` and others
   establishes `연결고리` as the canonical noun replacement when the
   particle is GYEOL_SUBS-vulnerable. Reuse keeps lexical voice
   consistent with the rest of the bundle.
2. **Three-noun parallel list preserved.** The fragment's parallel
   structure (`성장, 배움, X입니다`) matches the FIRE/EARTH/WATER/METAL
   sibling fragments in the same file (`표현, 온기, 추진력입니다`,
   `중심, 현실감, 지속성입니다`). A non-noun rephrase like `이어진
   흐름입니다` would break the three-item parallel and stand out
   stylistically.
3. **Post-processor stable.** `연결고리입니다` is not in GYEOL_SUBS (the
   substitution targets `결+particle`, not `결고리`), so the cell is
   stable both before and after the P19-A3 lookbehind.

Diff (single character insertion of `고리`):

```
-…삶을 좋게 만드는 열쇠는 성장, 배움, 연결입니다.…
+…삶을 좋게 만드는 열쇠는 성장, 배움, 연결고리입니다.…
```

The two adjacent paragraphs in the same `templateTokens.value` were
left unchanged.
