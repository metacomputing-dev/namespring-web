## Headline

10 owned-scope `standard.fragments.json` fragments hand-extended with a
5th paragraph. Six fragments (academic / career / family×2 / health /
overall — all from the P25-A2 lift batch) received an inserted
substantive new P4 (counterexample / cohort-specific / deeper-insight)
with the existing closing aphorism migrating to P5; four wealth
fragments (each a unique within-cluster representative) received an
appended short P5 closing aphorism. Sample regen confirmed cell
histogram delta `4p: 95 → 85 (−10)`, `5p: 237 → 247 (+10)`, exactly 1:1
fragment-to-cell as targeted. All required CI gates and validations
PASS.

## Workflow

1. **Candidate analysis**: ran `tally-4p.mjs` against owned-scope
   `<cat>/<period>/standard.fragments.json` (excludes `_*/`) filtering
   for ct=1 4p cells. Result: 20 candidates across 8 categories.
2. **Wealth duplication check**: `check-wealth-dup.mjs` revealed only 4
   *distinct* wealth templates among the 8 wealth candidates:
   - male.30_39.006 cluster (4 dups: thisMonth/thisWeek/thisYear/today)
   - female.40_54.007 cluster (2 dups: thisYear/today)
   - 55_69.009 (unique)
   - wildcard.001 (unique)
   To preserve voice diversity, picked **at most one fragment per
   duplicate cluster**.
3. **Selection** (10 fragments, 6 categories × 4 periods):

   | Fragment | Insert mode | 5th-paragraph kind |
   |---|---|---|
   | `academic.life.standard.10_19.003` | insert P4 | counterexample (slump 회복) |
   | `career.thisMonth.standard.age20_29.007` | insert P4 | cohort (또래 비교) |
   | `family.life.standard.balanced.012` | insert P4 | counterexample (받는 자리 미안함) |
   | `family.life.standard.elder.008` | insert P4 | counterexample (도움 받는 결) |
   | `health.today.standard.balanced.001` | insert P4 | counterexample (강행군 무리) |
   | `overall.thisMonth.standard.balanced.neutral.008` | insert P4 | counterexample (지루함 자책) |
   | `wealth.thisYear.standard.55_69.009` | append P5 | closing aphorism (정리·나눔) |
   | `wealth.thisYear.standard.female.40_54.007` | append P5 | closing aphorism (중년의 깊이) |
   | `wealth.thisYear.standard.male.30_39.006` | append P5 | closing aphorism (한 자리씩 차분히) |
   | `wealth.thisYear.standard.wildcard.001` | append P5 | closing aphorism (사계절 자기 자리) |

4. **Authoring strategy**:
   - **Insert mode (6 P25-A2-lifted fragments)**: previous P4 was a short
     closing aphorism (~30-40c); new substantive P4 inserted in the
     structural slot for counterexample / cohort / deeper-insight,
     pushing the closing to P5. Shape now matches existing 5p style
     (substantive body + short closing aphorism, ~37c P5).
   - **Append mode (4 wealth originals)**: existing P4 was substantive
     `주의할 결`; appended a short ~45-60c closing aphorism as P5,
     directly following the proven shape of `wealth.life.*` 5p fragments
     (e.g., `wealth.life.standard.55_69.008`).
   - All new paragraphs end in 해요/돼요/가요/이에요/만들어요/만들어 줘요/돌아와요/배워 가요/모여요/되어 줘요/부드러워져요/봐요/단단해져요/모여요/누리면 좋아요-style sentence-final endings.
   - No new tags introduced; voice and tier separation preserved.
5. **Sample regen**: `npm run samples:regen` produced fresh
   `artifacts/sample-outputs-2026-05-05-phase3/*-tiered.json` reflecting
   the new paragraph counts.
