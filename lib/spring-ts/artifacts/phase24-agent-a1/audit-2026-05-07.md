## Methodology choice — strict `< 3`

The task spec says `paragraphs.length < 3 → violation`. The historical
`measure_p23.mjs` uses `len > 0 && len < 3` (excludes empty). On the
current corpus both rules agree (no `len==0` standard cells exist),
but strict matches:

- the literal task wording,
- `--min-paragraphs=3` CLI semantics (anything below 3 fails),
- the regression-locking purpose (a future change that drops the
  `standard` tier wholesale should fail this gate, not silently pass
  because `len==0` is treated as "no tier to evaluate").

Decision recorded in the script header so reviewers don't read it as
divergence-by-accident.
