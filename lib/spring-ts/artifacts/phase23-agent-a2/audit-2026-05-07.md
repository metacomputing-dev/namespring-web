   `data/narrative/_coverage/min14-romance-plain-floor.fragments.json`
   (`romance.{period}.standard.ageband.child_teen.501`), each carrying
   only 2 paragraphs. The `_coverage` bundle is read-only for this
   agent (out of owned scope), so the fix must come from authoring
   higher-specificity minor-band fragments inside
   `data/narrative/romance/<period>/standard.fragments.json`.
3. **Author**: 10 new fragments (5 periods × 2 minor sub-bands):
   - `romance.life.standard.minor.child.001` — `agePhase: ["child_0_9"]`,
     `ageBand: ["0-9"]`. specificity = 2.
   - `romance.life.standard.minor.teen.001` — `agePhase: ["early_teen",
     "late_teen"]`, `ageBand: ["10-19"]`. specificity = 2.
   - `romance.today.standard.minor.{child,teen}.001` — same pattern.
   - `romance.thisWeek.standard.minor.{child,teen}.001` — same pattern.
   - `romance.thisMonth.standard.minor.{child,teen}.001` — same pattern.
   - `romance.thisYear.standard.minor.{child,teen}.001` — same pattern.

   Each fragment emits ≥ 3 paragraphs (life/teen at 3, life/child at 3,
   today/thisWeek/thisMonth/thisYear all at 3 paragraphs). Vocabulary:
   친구·가족 사랑, 좋아하는 사람과 보내는 시간, 기다림, 마음 표현
   (kid-/teen-friendly).
4. **Specificity bump**: Selector picks the candidate with the highest
   `specificityScore` (count of nonempty gating arrays after the
   `relaxBefore` cutoff;
   `src/report/tiered/fragment-selector.ts:76-83`). The two existing
   minor candidates for each cell are:
   - `romance.{period}.standard.{teen,child}.001` (single ageBand;
     specificity 1).
   - `_coverage/.../romance.{period}.standard.ageband.child_teen.501`
     (combined `[0-9, 10-19]`; specificity 1).

   Both authored at specificity 1 → tie broken by FNV-1a hash, leading
   to the 2-paragraph `_coverage` fragment winning ~50 % of seeds.
   The new `minor.{child,teen}.001` fragments add `agePhase` to the
   gating, lifting specificity to 2. They always win over both legacy
   candidates for the targeted minor fixtures, with no risk of breaking
   adult-band selection (adult fixtures don't satisfy
   `passesMinorGuard` for these new fragments because their ageBand
   excludes adult bands).
5. **Sample regen**: `npm run samples:regen` after fragment authoring
   confirms all 5 minor fixtures (04/18/27/30/31) × 5 periods ×
   romance now select the new `*.minor.{child,teen}.001` fragmentIds
   and emit 3 paragraphs each.
6. **Validation**: 15 production CI gates + 4 tier/schema tests, all
   PASS. See §Phase 23 acceptance gate results below.

## Tone / voice notes

Vocabulary follows NARRATIVE_STYLE_GUIDE §5 + the existing
`romance.{period}.standard.{child,teen}.001` patterns:

- 0-9 (child) frame: caregiver-shared 3rd-person ("아이는…"),
  친구·가족 자리, 단체 활동·놀이, 부모·선생님, 사람을 좋아하는 마음.
  No marriage / breakup / 짝 어휘 in determinative form. `cautions`
  always include "어른의 큰 약속 어휘를 너무 빨리 끌어오지 않아요"
  to soft-block premature adult framing.
- 10-19 (teen) frame: 또래·친구·동아리·학교·학원, 표현·발표·창작.
  좋아하는 사람과의 시간, 기다림, 한 박자 천천히 표현. 결혼·짝의
  큰 결정은 "한참 뒤의 이야기로 두면 돼요" framing only.

(1 entry); `paragraphs[].plainText` reads naturally after the
