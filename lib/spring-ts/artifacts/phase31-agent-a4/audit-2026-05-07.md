## Insertion mode (per fragment)

Two modes used, chosen per existing P3 structure:

- **insert-P3** (5 fragments): existing P3 is a single-sentence
  closing aphorism — new substantive paragraph inserted between
  P2 and the existing P3, which becomes P4. Matches P25-A2 / P26-A2
  / P29-A4 pattern.
- **append-P4** (5 fragments): existing P3 is already 2 substantive
  sentences — new paragraph appended as P4. Matches P26-A3 / P30-A1
  pattern.

## Per-paragraph spec

Per task constraints + P29-A4/P30-A1 lessons distilled:

- **96-115 chars** (within standard window; conservative vs P29-A4's
  93-165 range)
- **흐름이 = 0** in source per paragraph (post-processor budget=2 →
  rendered ≤2; flow-cluster threshold=3 stays clear)
- **결X = 0** in source per paragraph (avoids `reduceOverusedGyeol`
  substitution → `흐름X` clustering risk; P29-A1/P30-A1 lesson)
- sentence-final endings (~줘요/져요/돼요/예요/세요/아요/워요)
- no jargon, no new tags, pure `templateTokens[0].value` edit
- no axis/gating/livingTips/cautions/sourceTier change
