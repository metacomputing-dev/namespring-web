## Detection algorithm

```
For each category in {academic, career, expression_children, family,
                     health, health_stress, movement, overall, romance,
                     study_document, wealth} (11 concrete categories;
                     `_*` directories such as `_contract`, `_glossary`,
                     `_metaphor`, `_modifier_*`, `_seed`, `_coverage`
                     are skipped):
  For each period in {today, thisWeek, thisMonth, thisYear, life}:
    Read data/narrative/<cat>/<period>/standard.fragments.json
      (only the standard tier carries livingTips — brief / expert do not)
    For each fragment:
      Derive cohortStem from fragmentId by stripping
        "<cat>.<period>.standard." prefix
        (e.g. wealth.today.standard.male.30_39.006 → male.30_39.006)
      For each livingTip in fragment.livingTips:
        record (category, tipString) → periods × cohortStems

A (category, livingTipString) is a VIOLATION iff:
  distinctPeriods(tip) >= --min-periods (default 4) AND
  distinctCohortStems(tip) >= --min-cohort-stems (default 2)

Gate fails iff violationCount > --max-violations (default 0)
```

## Methodology notes

- **Source-level scan**, not sample-output scan. Unlike `ci:flow-cluster` / `ci:hook-coverage` / `ci:hook-concentration` which read `artifacts/sample-outputs-2026-05-05-phase3/*-tiered.json`, this gate consumes `data/narrative/<cat>/<period>/standard.fragments.json` directly. livingTips lives at the source level and the audits modified source directly; sample regen is therefore not in scope and `samples:regen` does not need to run before this gate.
- **Standard tier only.** Verified empirically (`brief.fragments.json` and `expert.fragments.json` carry no `livingTips`). The script hardcodes `standard.fragments.json` accordingly.
- **`category.period.standard.` prefix stripping** for cohort-stem derivation. The remainder is exactly the cohort label P28-A3/P30-A3/P31-A2/P31-A3/P32-A1 audits use to describe clusters.
- **Default flags chosen to match audit framing:** `--min-periods=4` matches the P28-A3 / P30-A3 / P31-A2 4-period verbatim language; `--min-cohort-stems=2` matches P30-A3's "cross-cohort" framing for `aligned.007 + aligned.008`. Both are configurable via CLI flags.
