## Per-paragraph spec

Per task constraints + P30-A1 / P33-A2 / P34-A2 / P35-A3 / P36-A2 /
P37-A2 distilled lessons:

- **106-124 chars** (within 100-150 task window; tighter than P37-A2's
  110-135 to keep cell-render below 150-char post-processor envelope)
- **흐름이 = 0** in source per paragraph (post-processor 흐름 budget
  = 2 -> rendered <= 2; flow-cluster threshold = 3 stays clear)
- **결 = 0 or 1** per paragraph (within audit-stated <=1 결 discipline;
  avoids `reduceOverusedGyeol` substitution -> `흐름X` clustering risk).
  Of the 8 P5s, 7 have 0 결 and 1 (`health.thisYear.strong.001`) has
  1 흐름 / 0 결 in source.
- sentence-final 요-endings (~줘요/져요/돼요/세요/어요/예요/etc.)
- no jargon (신강/신약/격국/십성/용신/etc.) — standard tier
- no axis/gating/livingTips/cautions/sourceTier change
- pure `templateTokens[0].value` edit only
