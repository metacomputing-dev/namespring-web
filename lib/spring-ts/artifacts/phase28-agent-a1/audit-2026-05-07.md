## 3. 변경 전략

각 cluster 에서 `today` (또는 첫 period) 는 원형 보존 → 사용자가 short period 를
주로 본다는 가정 + cluster 다양화. thisWeek/thisMonth/thisYear 는 phrasing 다양화.

다양화 옵션:
1. `X 가 아니라 Y` (rather than X)
2. `X 라기보다 Y` (more like X than Y)
3. `굳이 X 하기보다 Y` / `X 를 욕심내기보다 Y`
4. `X 하지 말고, Y` / `X 대신 Y`
5. negation 제거 후 긍정 reframing (e.g., "Y 에 마음을 묶지 말고 X 를 지키면 충분해요")

- 4-occurrence cluster 6 개 모두 → 0

  `굳이 ~보다`, `~지 말고` 등 분포 확대
- 일부 cell 은 contrast 자체를 제거하고 긍정 reframe 으로 표현 (Edit #5: "결과를
  욕심내지 않고") — "다양화" 가 단순 negation 어미 교체에 그치지 않음
