Three findings dominate this audit:

1. **Pre-fix vulnerable `_coverage/` 연결X count = 1** —
   `_coverage/yongshin-action-density.fragments.json:22` carries `…
   성장, 배움, 연결입니다.` (P19-A5 §I2 carry-over). Without P19-A3's

2. **Doubled `결이` cluster persists (11 brief.headline cells)** — P18-A4
   landed a cluster-aware guard in `compressBriefHeadline`. P19-A5 §I4
   logged that the guard regressed somewhere in the running-output chain.
   The pre-fix snapshot still reads 11 cells, all in
   `romance.thisMonth.brief.headline` with the exact P18-A4 target
   string `이번 달은 사람과의 결이 차분히 정돈되는 결이에요.` Per the
   plan, P20-A1 fixes this at the data layer (paraphrase the fragment
   so the second `결이` is a different vocabulary item) rather than
   re-investigating the src layer.

3. **`ci:samples-stale` has 15 stale samples** — the regen-drift cycle
   that P14-A5 → P18-A5 had closed re-opened during Phase 19 (P19-A5 §I1).
   P20-A3 owns the regen step + the `ci:post-processor-grammar`
   `--max-violations=2 → 0` ratchet that closes the cycle structurally.

## Phase 20 issues observed

### I1. Doubled `결이` cluster — 11 cells, all `romance.thisMonth`

Distribution:

- 11 cells, all `period=thisMonth`, `category=romance`, `surface=brief.headline`
- Identical text across all 11 fixtures: `이번 달은 사람과의 결이 차분히 정돈되는 결이에요.`
- Fixtures: `05-park-minji`, `06-lee-hajun`, `09-kim-seongsu`,
  `10-choi-yaza`, `13-oh-extreme-weak`, `17-kim-senior`,
  `23-jonggyeok-jongwang-yeomsang`, `28-jonggyeok-jonggang`,
  `29-pure-hangul-name`, `32-nonagenarian-weak`, `33-consensus-aware`

This is the same string P18-A4 targeted (`fae5a93`). P19-A5 §I4 logged
the regression. P20-A1 takes a data-side rephrase rather than another
src-side guard iteration: the source brief fragment that emits this
headline is rephrased so that one of the two `결이` becomes a different
vocabulary item (`흐름이` / `리듬이` / `호흡이` candidates). P20-A1's
`simulate.ts` (visible in the shared worktree) verifies that all three
candidate substitutions clear the doubled-`결이` regex.

### I2. `_coverage/yongshin-action-density.fragments.json:22` — `연결입니다`

The `연결입니다` form was missed by P18-A5's 7-particle table (it
covered `을/이/로/은/이/만/도/의` only). P19-A5 §I2 enumerated the
gap. With P19-A3's `(?<![가-힣])` lookbehind landed in
`src/report/tiered/template-engine.ts:GYEOL_SUBS`, the runtime mangling
risk is neutralised. P20-A2 closes the source data so the
post-processor never has to rely on the guard for this cell.

The P20-A2 commit (`88ff9a5` on `p20-a2-yongshin-cleanup` branch) makes
the substitution `… 성장, 배움, 연결입니다.` → `… 성장, 배움, 연결고리입니다.`
keeping the three-noun parallel list (`성장, 배움, X입니다`) consistent
with sibling FIRE/EARTH/WATER/METAL fragments in the same file.

### I3. `ci:samples-stale` regen-drift cycle (15 stale samples)

Same 15-fixture FAIL as P19-A5 §I1. Two upstream causes:

1. P18-A5's source rephrasing (`연결X → 연결고리X`) for two cells was
   regenerated but specific cells in `14-choi-palace-naeum-surface`,
   `25-jonggyeok-jonggwan`, `35-palace-naeum-female-mid` re-introduced
   after the regen via ordering changes.
2. P19-A1's `overall/life/branching.fragments.json:147` data fix
   (commit `9705478`) was committed without a follow-up
   `samples:regen`; the 13 fixtures touched by `livingTips` for
   `overall.life` regen-diverge until a regen is included.

Resolution: P20-A3 owns `npm run samples:regen` after P20-A1 + P20-A2
land, then ratchets `ci:post-processor-grammar` to `--max-violations=0`
(currently `=2`).

### I4. `ci:acceptance-completeness` FAIL — `ci:hook-coverage` undeclared

Same as P19-A5 §I3. The script `ci:hook-coverage` was added to
`package.json` in P19-A4 (commit `422a9a6`) but its acceptance manifest
entry has not landed on main yet. P20-A4 (committed `81e9e79` on
`p20-a4-acceptance-completeness` branch) adds the `accepted[]` entry.
Self-contained 1-line manifest edit.

### I5. `ci:post-processor-grammar` 2 leak cells (sample drift)

`compound_yeon_flow: 2` from the post-processor leak monitor. Both
cells are stale-sample drift (`25-jonggyeok-jonggwan.life.overall.expert`,
`35-palace-naeum-female-mid.today.overall.standard`). The underlying
source data in those fragments is already `연결고리` (post-P18-A5),
but the samples were not regenerated. Resolves automatically on P20-A3

The `ci:post-processor-grammar` gate currently uses
`--max-violations=2` (P19-A2 ratchet). After the regen P20-A3 ratchets
to `=0`, locking the post-processor leak class permanently.
