## What this gate locks

Source of truth (single string sentinel):

```
src/report/tiered/build-tiered-matrix.ts:49
const PLACEHOLDER_BRIEF: BriefFortuneText =
  Object.freeze({ headline: '준비 중인 흐름이에요.' });
```

`PLACEHOLDER_BRIEF` is returned at three sites in `build-tiered-matrix.ts`:

| Line | Context |
|------|---------|
| 162  | `if (!text) return PLACEHOLDER_BRIEF;` (inner brief renderer; render result empty) |
| 348  | `const brief = briefRender ? deriveBrief(...) : PLACEHOLDER_BRIEF;` (selector returned no fragment) |
| 367  | `brief: PLACEHOLDER_BRIEF` (period-level early-return for ineligible cells) |

Each path emits the literal `'준비 중인 흐름이에요.'` headline into a
service-visible cell. P23-A1 closed all 8 service-visible PLACEHOLDER
cells by authoring the missing minor-band brief fragments
(`overall × {today, thisWeek, thisMonth, thisYear}` teen-only,
`health_stress × today` child-only). This gate prevents regression by
failing CI if any sample fixture re-introduces the literal at a brief
headline.

Standard- and expert-tier `PLACEHOLDER_*` use `EMPTY_PARAGRAPHS`
(no string sentinel). Those tiers are P24-A1's
`ci:standard-paragraph-floor` territory; this gate intentionally does
not overlap.

## Detection rule

Exact-match (`===`) against `'준비 중인 흐름이에요.'` at every

- `payload.tieredMatrix.periods.<period>.overall.brief.headline`, and
- `payload.tieredMatrix.periods.<period>.byCategory.<category>.brief.headline`

across every `.json` fixture in
`artifacts/sample-outputs-2026-05-05-phase3/` except `index.json`. Five
periods × (1 overall + 10 categories) = 55 cells per fixture × 32
tiered fixtures = **1760 cells**.

Per advisor guidance: no fuzzy/partial match. The src truth is one
literal; broadening would create a moving definition and risk false
positives on intentional headlines that happen to share the
`준비`/`흐름` lemmas.

Fixtures without `payload.tieredMatrix.periods` are recorded under
`fixturesSkipped` and excluded from cell counts:

| File | Reason |
|------|--------|
| `01-choi-seongsoo-current-fortune.json` | non-tiered current report |
| `03-choi-seongsoo-spring-report-vector.json` | spring-report-vector dump |
| `07-choi-seongsoo-candidate-summaries.json` | candidate-summaries dump |
| `diff-legacy-vs-tiered.json` | legacy-vs-tiered diff artifact |
