# Phase 10 Agent A5 — Comprehensive Prose Audit

Date: 2026-05-06
Owner: P10-A5
Scope: `lib/spring-ts/data/narrative/` (excl. `_glossary/`, `_metaphor/`, `_modifier_*/`, `_seed/`, `_contract/`) and rendered prose in `artifacts/sample-outputs-2026-05-05-phase3/`

## Headline

After Phase 3-9 cumulative ~120 commits, the prose layer is in good shape. This
audit scanned **3,135 prose units** across **19 fixtures × 5 periods × 11
categories × 3 depths**, plus **3,912 fragments across 344 bundle files** at
the data layer. **9 broken Korean endings** and **9 spelling typos** were found
and fixed in this phase.

After P10-A5 fixes:

- Hard contracts: still 0 violations.
- Service voice audit (`ci:narrative-voice`): 0 / 0 / 0.
- Cell axis coverage (`ci:narrative-cell-axis`): 0 / 0 / 0.
- typecheck: PASS, no-ai-policy: PASS, namespring-compat: 202/202.

## Audit methodology

1. `extract-prose.mjs` — walks each sample fixture's `tieredMatrix` and emits
   each `(fixture, period, category, depth, plainText)` record.
2. `audit-scan.mjs` — runs ~20 issue detectors on every prose unit
   (broken endings, awkward phrases, cross-period leak, voice violations,
   English bleed, particle bugs, expert tagging, etc.).
3. `scan-fragments.mjs`, `scan-fragments-v2.mjs`, `scan-fragments-v3.mjs` —
   data-layer scans (typos, double-space, paren balance, hashtag in plain
   depth, etc.).
4. `scan-truncated.mjs` — noun + bare `요.` ending detector.
5. `scan-glossary-coverage.mjs` — verifies every used `tagId` is registered
   and every used `label` matches the glossary's canonical label.

## Issue catalog

### A. Direct fixes applied this phase

#### A1. Broken Korean endings (severity: high) — FIXED 9 instances

Detector found nouns/verb stems followed by bare `요.` (no copula or
conjugation). All in `_coverage/`:

| File | Old | New |
|------|-----|-----|
| `_coverage/birth-season-density.fragments.json` | `삶을 넓요.` | `삶을 넓혀 가요.` |
| `_coverage/current-season-density.fragments.json` | `방향을 먼저 정요.` | `방향을 먼저 정해요.` |
| `_coverage/current-season-density.fragments.json` | `정리하고 고르는 선택요.` | `정리하고 고르는 선택이 좋아요.` |
| `_coverage/current-season-density.fragments.json` | `준비하고 회복하는 선택요.` | `준비하고 회복하는 선택이 좋아요.` |
| `_coverage/min12-density-floor-complete.fragments.json` | `일찍 쉬는 습관요.` | `일찍 쉬는 습관이 좋아요.` |
| `_coverage/min14-health-floor.fragments.json` | `같이 잡아야 컨디션요.` | `같이 잡아야 컨디션이 단단해져요.` |
| `_coverage/min14-health-floor.fragments.json` | `고르게 유지하면 회복요.` | `고르게 유지하면 회복이 빠르게 잡혀요.` |
| `_coverage/min14-study-document-plain-floor.fragments.json` | `중요한 결정이 쉬요.` | `중요한 결정이 쉬워져요.` |
| `_coverage/min15-axis-value-floor.fragments.json` | `자주 묻는 습관요.` | `자주 묻는 습관이 잘 맞아요.` |

Likely cause: AI-generation artifact where the verbal/copular suffix was
truncated at the end of the sentence. Detector regex (see
`scan-truncated.mjs`) catches noun + bare `요.` and verb-stem-1-syllable +
bare `요.`.

#### A2. Spelling typo — `조장궁` → `조상궁` (severity: high) — FIXED 9 instances

The glossary entry `palace.json` defines `id: jojangung, label: 조상궁`.
Nine fragment files used `label: 조장궁` (장 instead of 상), creating
visible spelling inconsistency in rendered prose.

Files fixed:
- `overall/today/expert.fragments.json` (1)
- `overall/thisYear/expert.fragments.json` (1)
- `overall/thisMonth/expert.fragments.json` (1)
- `overall/thisWeek/expert.fragments.json` (1)
- `overall/life/expert.fragments.json` (1)
- `_coverage/min14-movement-expert-floor.fragments.json` (3)
- `_coverage/min15-family-floor.fragments.json` (1)

Note: 120+ instances correctly used `조상궁` already; only these 9 were the
typo variant. Underlying cause: the glossary `id` is `jojangung` (Romanization
of 조장궁), but the canonical Korean label is 조상궁. The romanized id is the
historical artifact and was not corrected. Fragment authors may have
back-translated `jojangung` → `조장궁` in some places. Glossary id remains
unchanged (would be a breaking schema change); only `label` strings were
aligned.

#### A3. English bleed — `polarity` → `일간 음양` (severity: medium) — FIXED 6 instances

`_coverage/expert-neutral-polarity-density.fragments.json` had 6 prose
fragments using English word `polarity` directly:

```
"중립 polarity이면 이번 주 건강 판단은..."
"중립 polarity의 가족운은..."
```

Replaced with `일간 음양 중립` / `일간 음양이 중립` to align with the same
file's first fragment (line 28: `일간 음양이 중립으로 잡히는 구조라면...`).

### C. Outstanding issues (defer to later phase)

#### C1. Glossary label inconsistencies (severity: low)

After P10-A5 fixes, **14 distinct glossary `label` mismatches remain** between
`_glossary/*.json` canonical labels and fragment-level `tag.label` overrides
in 200+ instances total:

| tagId | glossary | used variants | total variant fragments |
|-------|----------|---------------|------------------------|
| `stabilityIndex` | `안정성지수` | `안정 지표` (18), `안정 지수` (13) | 31 |
| `yongshinFit` | `용신부합도` | `용신 부합도`, `용신적합도` | 28 |
| `gyeokgukFit` | `격국적합도` | `격국 적합도` | 151 |
| `eumyangHarmony` | `음양조화도` | `음양 조화`, `음양조화` | 52 |
| `sajuCompatibility` | `사주적합도` | `사주 적합도`, `사주궁합`, `사주 적합성` | 57 |
| `ohaengBalance` | `오행균형도` | `오행 균형` | 6 |
| `fire` | `불` | `화` | 8 |
| `earth` | `흙` | `토` | 2 |
| `water` | `물` | `수` | 8 |

Why deferred:
- Mass replacement (200+ fragments) and may collide with template-engine.ts
  particle normalization (`hasFinalConsonant(label)`) which is sensitive to
  the specific Korean spelling.
- Sino-Korean fire/earth/water (`화`/`토`/`수`) variants in 18 fragments may
  be intentional register matching with surrounding `한자어` (Sino-Korean)
  prose like `활동 압력`, `진정력`. Decision needs author intent confirmation.
- The 200+-instance batch replace is a coherent unit of work better done
  in a dedicated phase with a single-purpose commit log.

Recommendation: Phase 11 dedicated PR — bulk align all `tag.label` to
glossary canonical, with a single test that asserts label==glossaryLabel
for every used `tagId`.

#### C2. Cross-period leak from `template-engine.ts` (severity: medium, src/ scope)

`src/report/tiered/template-engine.ts:407` contains an unconditional
rewrite:

```ts
out = out.replace(/잠을 충분히 챙기는 자리예요/g, '잠을 충분히 챙기는 하루예요');
```

This is meant for `today/health_stress` cells but fires on `thisWeek/
health_stress` too, producing the only currently-live cross-period
mismatch:

```
이번 주는 잠을 충분히 챙기는 하루예요. 햇빛 아래 짧은 산책이 좋아요.
       ^^^^                       ^^^^^^^^
```

The fragment at `_coverage/.../thisWeek/brief.fragments.json:303` correctly
says `이번 주는 잠을 충분히 챙기는 자리예요.`; the renderer rewrite breaks
that. Out of P10-A5 scope (forbidden src/). Recommend src/ owner trim or
period-gate the rewrite.

#### C3. Romanization-vs-Korean schema artifact (severity: very low)

`palace.json` glossary entry `id: jojangung` is the romanization of `조장궁`,
but its canonical Korean label is `조상궁`. The id was originally generated
from a misspelling and is now load-bearing across fragment-level `tagId`
references (110+ files). Renaming requires schema migration. P10-A5 fix
left `tagId` as-is and only updated `label` to `조상궁`.

Recommendation: track in a separate refactor backlog item; not user-visible
because `tagId` is a programmatic identifier, not displayed.

## Recommendations for next phase

### High priority

1. **Phase 11 — Glossary label normalization sweep (C1 above).** Single-
   purpose PR aligning all 200+ `tag.label` mismatches to glossary
   canonical, with a new `ci:narrative-tag-label-alignment` gate.
   Estimated: 1 day, single commit.

2. **Phase 11 (or P10-A6) — `template-engine.ts` cross-period rewrite trim
   (C2 above).** Either gate the `자리예요` → `하루예요` rewrite to
   `period === 'today'` only, or remove the wholesale string replacement
   in favor of fragment-level prose authoring. Out of A5 scope but
   important user-visible bug. Single src/ commit.

### Medium priority

3. **DayMaster metadata exposure on `tieredMatrix`.** Adding
   `tieredMatrix.profile.dayMasterElement` would let cross-element-metaphor
   detection run automatically. Currently the audit must skip this category
   because the rendered output doesn't contain the day-master.

4. **Detector productionization.** The `scan-truncated.mjs` and
   `scan-glossary-coverage.mjs` scripts in this phase are valuable enough
   to promote into `tools/` as reusable CI gates. Suggested commands:
   - `npm run ci:narrative-truncated-endings` — fail if any noun + bare
     `요.` (with whitelist for valid copulas).
   - `npm run ci:narrative-tag-label-alignment` — fail if any `tag.label`
     != glossary canonical for the same `tagId`.

### Low priority / backlog

5. **Phase 12 — `tagId` romanization audit (C3 above).** Catalog all
   `tagId` values where the romanization disagrees with the current Korean
   label, and decide on a migration plan. Not user-visible but creates
   maintenance friction (next author sees `jojangung` and may reintroduce
   `조장궁` typo).

6. **Idiom whitelist refinement.** The `cross_period_leak` filter
   (`IDIOMATIC` regex) was tuned to match this corpus; if new fragments
   add new idiomatic time-period uses, the filter may need extension.
   Maintain alongside `scan-truncated.mjs`.
