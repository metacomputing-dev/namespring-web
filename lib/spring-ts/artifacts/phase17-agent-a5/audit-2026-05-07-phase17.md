   `lib/spring-ts/src/**`, `saju-ts/src/**`, and the sample artifacts
   directory.
c. Document the regen-after-data-fix protocol in the agent handoff
   doc so subsequent A* agents know to invoke `npm run samples:regen`
   (or the equivalent `tools/regen_samples.mjs` invocation) when their
   data fix may shift sample output.
