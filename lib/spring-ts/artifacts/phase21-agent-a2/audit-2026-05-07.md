## Headline

The `depth_inversion` detector compared raw `plainText.length` between the
brief headline and the standard tier's first paragraph. With both surfaces
tightly bounded (brief 28-40 chars, standard first-sentence 30-45 chars)
length deltas of 1-8 chars produced **113 hits across genuinely-different
prose** — pure noise. The original P5 / P6 / P7-A1 era detector
(`audit-prose.mjs:228-249`) measured Levenshtein similarity between
particle-stripped, whitespace-normalized forms and flagged near-duplicates
at >= 0.75 ratio. That intent was lost when the detector was ported into
`audit-phase12.mjs` — only the length comparison survived.

P21-A2 restores the semantic intent. After refresh:

- 1,760 (period × category × fixture) cell pairs evaluated.
- 18 hits at >= 0.75 similarity (vs 113 length-only false positives prior).
- 14 of 18 cluster in `thisMonth/movement` — single shared template
  `이번 달 이동운은 익숙한 동선에서 한 발짝씩 넓혀 가기 좋은 모습이에요`
  whose first sentence is essentially the brief headline with `이동운은`
  inserted and `좋아요` → `좋은 모습이에요` swapped.
- 4 single-fixture hits in `thisYear/career`, `thisMonth/expression_children`,
  `today/overall`, `today/academic` — each a different template that needs
  a brief or standard-para0 rephrase.

These are real depth-overlap signals that the standard tier should add
content beyond the brief tier's 28-40 char headline. They are recommended
rephrase candidates for Phase 22+ (data work, out of P21 scope).

## Decision

**Refresh, not deprecate.**

Reasoning:

1. The signal is real and useful — brief vs standard saying the same thing
   IS a quality issue worth a guard. Audit doc writers in P14 / P15 / P16 /
   P17 / P18 / P19 / P20 each reflagged the detector as noise without
   refreshing.
2. The original P5 detector intent (Levenshtein similarity ≥ 0.75 on
   normalized forms) is preserved in `phase5-prose-audit/audit-prose.mjs:228-249`.
   Restoring that algorithm is a 78-line edit confined to lines 140-165 of
   `audit-phase12.mjs`.
3. Deprecating leaves the audit framework with one fewer detector for a
   real concern at zero algorithmic improvement.

## Algorithm

```
function detectDepthInversion(records, fixtureName):
  for each (period, category) cell in fixture:
    brief    = items where depth=brief and slot=headline
    standard = items where depth=standard and slot=plain|para0
    if both exist:
      a = normalize(brief.plainText)
      b = normalize(standard.plainText)
      if min(len(a), len(b)) < 6: skip
      ratio = 1 - levenshtein(a, b) / max(len(a), len(b))
      if ratio >= 0.75: emit hit

normalize(text):
  s = first sentence (split on . ! ? \n)
  s = strip whitespace
  s = strip punctuation . , ! ? ·
  s = strip up to 4 trailing particles from { 은 는 이 가 을 를 의 에
        에서 와 과 도 만 으로 로 요 예요 이에요 이다 다 }
  return s
```

Threshold 0.75 matches the P5 original `ratio < 0.25` distance threshold.
Min length 6 filters degenerate fragments.
