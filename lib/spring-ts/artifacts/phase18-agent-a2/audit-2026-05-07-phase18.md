## Methodology

`measure_p18_a2.mjs` is a read-only audit tool that:

1. Walks `data/narrative/{academic,career,…}/{today,thisWeek,thisMonth,
   thisYear,life}/brief.fragments.json` and collects every fragment with
   a non-empty `hook` field.
2. Walks `artifacts/sample-outputs-2026-05-05-phase3/*-tiered.json` and
   collects:
   - `cell.selectedFragments.brief.fragmentId` for cells where
     `cell.brief.hook` is set (the source-of-truth fragmentId selected
     by the engine for each cell).
   - `cell.brief.hook` (the rendered hook text, post substitution).
3. Computes two dormancy views:
   - **Per-fragment slot**: an authored fragment with `hook` whose
     `fragmentId` never appears in the engine's selection across any
     cell in any fixture. This is the strict "this slot was never
     selected" measurement.
   - **Per-hook text**: an authored hook string that never appears as
     `cell.brief.hook` (after applying the `template-engine.ts`
     post-processor's `결이/결을/결로` substitutions, which are the only
     mutations that affect hook text in the corpus).

The two views can disagree when multiple fragments share the same hook
text — the per-text view is more permissive. P18-A2's audit uses both
to expose any structural blocker.
