fragments already had substantive P4 content from prior 3p→4p lifts

## Per-paragraph spec

Per task constraints + P30-A1 / P33-A2 / P34-A2 distilled lessons:

- **105-126 chars** (within 100-150 task window; this batch ranges
  105-126)
- **흐름이 = 0** in source per paragraph (post-processor 흐름 budget
  = 2 → rendered ≤ 2; flow-cluster threshold = 3 stays clear)
- **결 ≤ 1** per paragraph (audit-stated discipline; 8 frags have 0 결,
  2 frags have 1 결; avoids `reduceOverusedGyeol` substitution →
  `흐름X` clustering risk; P29-A1 / P30-A1 / P31-A4 / P32-A2 / P34-A2
  lesson)
- sentence-final 요-endings (~줘요/져요/돼요/세요/어요/예요/etc.)
- no jargon (신강/신약/격국/십성/용신/etc.) — standard tier
- no axis/gating/livingTips/cautions/sourceTier change
- pure `templateTokens[0].value` edit only
