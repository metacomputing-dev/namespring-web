## Fragment-by-fragment changes

### 1. `movement.thisMonth.standard.weak_neutral.010` (covers 14 cells)

Brief (post-template-engine):
```
이번 달은 익숙한 동선에서 한 발짝씩 넓혀 가기 좋아요.
```

Standard first sentence — before:
```
이번 달 이동운은 익숙한 동선에서 한 발짝씩 넓혀 가기 좋은 모습이에요.
```

After (now leads on the gradual-pace framing; the
`익숙한 동선` cadence has moved to the second sentence and the
`한 발짝씩` lexeme has shifted to `한 걸음씩`):
```
이번 달 이동운은 갑작스러운 한 번의 큰 변화보다 활동 범위를 천천히 넓혀 가는
호흡이 잘 맞는 모습이에요. 익숙한 동선을 한 축으로 두고 결을 한 걸음씩 키워
가면 한 달의 흐름이 단단해져요.
```

Affected fixtures (all 14 hit the same fallback fragment via
`weak_neutral` gating): 02, 08, 11, 12, 14, 15, 16, 20, 21, 22, 24, 25,
26, 35.

### 2. `career.thisYear.standard.age10_19.006` (fixture 04)

Brief:
```
올해 마음을 흔드는 관심사 한 가지를 길게 살펴봐요.
```

Standard first sentence — before / after:
```
- 올해는 마음을 흔드는 관심사 한 가지를 길게 살펴보기 좋은 해예요.
+ 올해는 한 분야의 자료·책·짧은 시도를 한 줄씩 모아 두면 미래의 선택지가 자기에게 맞춰져 오는 한 해예요.
```

The new lead foregrounds the data-collection framing already implicit
in the original second sentence; the brief's "관심사 한 가지" angle is
echoed but not repeated verbatim.

### 3. `expression_children.thisMonth.standard.30_39.005` (fixture 29)

Brief:
```
이번 달은 가까운 사람과의 협업이 표현을 넓혀 줘요.
```

Standard first sentence — before / after:
```
- 이번 달은 가까운 사람과의 협업이 표현을 한 단계 넓혀 주는 흐름이에요.
+ 이번 달은 두세 명과 함께 만들 수 있는 작은 협업이 자기 표현의 결을 한 단계 단단히 다져 주는 흐름이에요.
```

The new lead pivots to the concrete "두세 명과 함께" framing that the
original second sentence carried.

### 4. `overall.today.standard.polarity.yin.404` (fixture 22)

Lives in `_coverage/min14-foundation-floor.fragments.json`.

Brief:
```
오늘은 바로 밀어붙이기보다 살펴보고 다듬는 힘이 좋아요.
```

Standard — before / after:
```
- 오늘은 바로 밀어붙이기보다 상황을 살피고 다듬는 힘이 좋아요. ...
+ 오늘은 살피는 시간과 움직이는 시간을 짧게 번갈아 두면 하루 흐름이 부드럽게 이어지는 결이에요. 준비만 길어지지 않게 작은 실행 한 가지를 함께 두면 살핀 만큼 결과가 또렷해져요.
```

The original third sentence's "살피는 시간과 움직이는 시간" cadence is
promoted to the lead so the standard tier opens on a new framing
beyond the brief's "밀어붙이기보다" line.

### 5. `academic.today.standard.55plus.006` (fixture 25)

Brief:
```
오늘은 좋아하는 책 한 페이지를 음미해도 좋아요.
```

Standard — before / after:
```
- 오늘은 좋아하는 책 한 페이지를 음미하기 좋은 흐름이에요. 빠른 학습보다 한 줄을 곱씹어 보는 흐름이 더 잘 어울리는 자리예요.
+ 오늘은 빠른 학습보다 한 줄을 곱씹어 보는 흐름이 더 잘 어울리는 하루예요. 좋아하는 글의 한 페이지를 천천히 따라 읽으면, 익숙한 문장에서도 새로 보이는 리듬이 자연스럽게 떠올라요.
```

The "한 줄을 곱씹어" cadence (originally sentence 2) becomes the lead;
the brief's "한 페이지를 음미" cadence is echoed via "한 페이지를 따라
읽으면" without lexical overlap.
