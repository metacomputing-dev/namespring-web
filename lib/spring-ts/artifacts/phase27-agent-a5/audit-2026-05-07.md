## Phase 28+ recommendations

### High priority

1. **Phase 27 post-merge audit (P27-A6 pattern)**. After P27-A1 / A2 /
   A3 / A4 all merge, run a `samples:regen` + integrated 18-gate measurement
   to verify sibling composition arithmetic. Mirror P26-A6's structure
   (sibling-merge composition verification table + per-sibling delivery
   target verification table).

2. **Hook concentration ceiling decision** (post-P27-A1). With current
   margin 3 vs `--max-hooks=20` and P27-A1 adding ~12 hooks, the
   post-merge max will likely be 18-19. Decision required: (a) accept
   margin 1-2 and continue narrow-gating in Phase 28+ (riskier), or
   (b) ratchet `--max-hooks` to 22-25 in a Phase 28 commit (gives
   3-5 phases of headroom). P25-A5 §Rec #6 + P26-A6 §Rec #1 carry over
   here.

3. **Hook richness saturation strategy (Phase 28+)**. If P27-A1 reaches
   ~60 distinct hooks, the cell × hook-eligibility space starts to
   saturate (32 fixtures × ~5 cells = ~160 hook-emit slots; 60 distinct
   hooks at 5-6 emits each = 300-360 occurrences ≈ current 345 ceiling).
   Lateral expansion options (P26-A6 §Rec 8 carry-over):
   - (a) hook variants per cell-rendered text (multi-render brief),
   - (b) tighter audience cohort × dayMasterStrength × seasonContext
     gating to push specificityScore higher and let more authored hooks
     fire deterministically.

### Medium priority

4. **Standard 4p+5p band growth pacing** (P26-A6 §Rec 6, 7 carry-over).
   Current 4p+5p = 352 / 1705 = 20.6 %. Phase 27-A3 lift takes this to
   ~352 cells (4p drops by 10, 5p gains 10, net 0). To reach 25-30 %
   in 3-4 phases, future siblings need to lift ~75-150 fragments from
   3p → 4p+5p. Per-phase commit ≤ 300 LOC pacing applies.

5. **Workflow YAML ship**:
   `.github/workflows/spring-ts-samples-stale.yml`. **Eleventh
   consecutive carry-over** (P19/P20/P21/P22-A5/A6/P23-A5/P24-A5/
   P25-A5/P26-A5/P26-A6/P27-A5 §Recommendations). The recommendation
   has not advanced because workflow YAML changes require OAuth
   permission elevation that no single agent has. Suggest a
   maintainer-owned PR.

6. **Build-determinism investigation closure** (P26-A6 §Rec 5 carry-
   over). P24-A4 first surfaced iso-vs-main dist drift; P25-A5 confirmed
   reproducibility; P26-A1/A2/A3/A4/A6 each ran a regen and committed
