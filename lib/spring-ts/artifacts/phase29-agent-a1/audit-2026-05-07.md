## Root cause analysis

### Why per-paragraph 흐름이 ≥ 3 surfaced

The audit-phase12 `flowCluster` detector counts `흐름이` matches per
rendered paragraph and flags any paragraph with ≥ 3. The P15-A4
informational lock keeps this metric at 0 to maintain stylistic variety.

P28-A2 added a fifth paragraph to two fragments. The source for both
new paragraphs contains:
- 1× literal `흐름이라`/`흐름이에요` (intentional final clause), AND
- 2× source `결이`/`결로`/etc. that the post-processor's
  `reduceOverusedGyeol` cycle converts to `흐름X` while the substitution
  budget is still open.

Crucially, `reduceOverusedGyeol` runs per **text token**, not per
**rendered paragraph** (`template-engine.ts:1021` — `resolveTokens`
calls `normalizeRenderedText` on each individual text token's value).
The `appliedFlow` budget resets at every tag-token boundary. So a
paragraph split internally by tag tokens gets multiple independent
`결X → 흐름X` substitution allowances, and the resulting density only
becomes visible after `mergeAdjacentText` joins the tokens for plain
text rendering.

## Fix detail

Two single-token source edits, each replacing one literal `결이` —
appearing immediately after a tag token — with `기운이`. Rationale:
- `기운이` is a non-substituting form (`reduceOverusedGyeol`'s GYEOL_SUBS
  pattern table only matches `결X` particle forms; `기운이` is left as-is),
- it preserves the original semantic weight (warmth/energy flowing
  through the family/scene),
- it matches the surrounding ~해요 expert tier voice without disturbing
  any other paragraph or breaking any glossary tag.

### Edit 1: `family.life.expert.young_caregiver.008` paragraph 5

```diff
        {
          "kind": "text",
-         "value": "에 따뜻한 결이 도는 어린 시기엔 보호자의 호흡과 "
+         "value": "에 따뜻한 기운이 도는 어린 시기엔 보호자의 호흡과 "
        },
        {
          "kind": "tag",
          "tagId": "jeongin",
```

Pre-fix render: `… 따뜻한 흐름이 도는 … 신뢰의 흐름이 청년기·중년기로 … 뿌리가 되는 흐름이라`
(3× `흐름이`).
Post-fix render: `… 따뜻한 기운이 도는 … 신뢰의 흐름이 청년기·중년기로 … 뿌리가 되는 흐름이라`
(2× `흐름이`).

Post-fix render: `대운궁실의 큰 기운이 #희신의 자리와 함께 … 받아들이는 흐름이 자라고 … 더 또렷한 리듬으로 모이는 흐름이에요`
