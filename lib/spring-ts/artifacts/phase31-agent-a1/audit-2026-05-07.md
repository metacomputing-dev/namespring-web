## 3. 변경 전략

P28-A1 / P30-A2 anchor 규칙 따름: `today` (또는 첫 period) 는 canonical 으로 보존,
나머지 period diversification. cross-trunk cluster (`큰 처방보다`, `큰 무대보다`) 는
cluster 가 가장 큰 trunk (`senior_55_69.001`, `weak_neutral.010`) 를 우선 분리.

다양화 옵션 mix:
1. `X 라기보다 Y` (introduce: 기존 2 회 → +2 도입)
2. `X 가 아니라 Y` / `X 결이 아니라 Y` / `X 자리가 아니라 Y`
3. `X 대신 Y`
4. `X 욕심내기보다 Y` (3 회 도입)
5. `X 하지 말고 Y` / `X 마음을 묶지 말고 Y` / `X 매이지 말고 Y`
6. `X 들기보다는 Y` / `X 앞세우기보다 Y` (`기보다`/`기보다는` 단조 회피)
