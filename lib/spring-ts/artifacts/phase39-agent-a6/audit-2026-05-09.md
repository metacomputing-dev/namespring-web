## P39-A1 leak-fix novelty (first data-edit sibling)

P39-A1 introduces the **5th sibling shape** in cycle taxonomy:
**data-edit** (vs prior data-add / 0-mutation / gate-add /
ratchet-review). The owned scope is **a single 1-character insert**
into existing authored content to flip a snapshot diagnostic.

**Mechanism**: the walk_eul detector pattern
`(?<![발첫한잰빠])걸음을` flags any `걸음을` whose immediate-preceding
character is not in the safe-list `[발, 첫, 한, 잰, 빠]`. P38-A2's
"내일 첫 걸음을 어디서" had a **space** as the immediate-preceding
char (the safe-list whitelists only the no-space form `첫걸음을`).
P39-A1's edit changed the phrase to "내일 첫 발걸음을 어디서" — now
`발` is the immediate-preceding char to `걸음을`, and `발` is on the
safe-list. Snapshot leak flips 1 → 0.

**Semantic preservation**: the rephrased sentence keeps the same
"start of tomorrow" framing ("내일의 첫 [발]걸음을 어디서 시작할지" →
identical 어디서 시작 verb clause + same 자기 손으로 또렷이 잡혀요
close). 발걸음 is a near-synonym (both mean "step / footstep") so
fragment voicing is preserved.

**Snapshot-vs-CI-gate gap path (a) closed**: P38-A6 §"Snapshot leak
+1" filed three follow-up paths for the walk_eul gap:
- **(a)** data-fix in a later phase (lowest effort, doesn't change
  gate contracts) — **CLOSED by P39-A1**.
- **(b)** Tighten the gate's regex to match the 띄어쓰기 form
