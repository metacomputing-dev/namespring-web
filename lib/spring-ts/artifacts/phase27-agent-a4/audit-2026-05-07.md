# Phase 27 Agent A4 — Standard Tier First-Sentence Diversification

Date: 2026-05-07
Branch: `phase27-agent-a4`
Worktree: `C:/Projects/metaintelligence/p27-a4-iso`

## Goal

Pre-emptively diversify standard-tier first sentences whose Levenshtein
similarity to the corresponding `brief.headline` falls into the 0.6–0.75
**marginal band**.

Phase 21-A2 hardened the depth-inversion detector at the >= 0.75 threshold
and the corpus currently produces 0 hits at that level. The marginal band is
where genuine future regressions would land first; pulling those cells below
0.6 widens the safety margin without rewriting prose that is already
materially distinct.

## Methodology

Reused the P21-A2 depth-inversion comparator from
`artifacts/phase12-agent-a5/audit-phase12.mjs`:

1. Particle-stripped, whitespace-normalized form of `brief.headline`
2. Particle-stripped, whitespace-normalized form of `standard.paragraphs[0]`
3. `1 - levenshtein(a, b) / max(|a|, |b|)`
4. Buckets: high `>= 0.75`, marginal `0.6 <= s < 0.75`, safe `< 0.6`

Implementation in `audit-marginal.mjs` (this folder); writes
`marginal-cells.json`.

### Notes on post-processor interactions

- `lib/spring-ts/src/report/tiered/template-engine.ts` was untouched per
  scope; the rewrites had to coexist with its existing replacement passes.
- `결X` particle forms get rewritten to `흐름X` by the gyeol-density
  reducer. Edits 2 and 4 had to abandon `결을` mid-sentence to avoid
  rendering as `흐름을 다져 가는 흐름이에요`; both now use `색을` as the
  alternative noun, which renders cleanly.
- `익숙한 자리에서 한 발짝씩 넓혀` is rewritten to `익숙한 동선에서 한
  발짝씩 넓혀` (template-engine.ts:532); edits 8 and 9 deliberately use
  `평소 다니던 길` so they bypass that pass and stay distinct from the
  brief, which still keeps `자리`-form input and ends up `동선`-rendered.
- All edits preserve `브리프 → 표준 → 전문` voice separation
  (no glossary tags, no jargon, no truncated endings).
