## 1. Issue 카테고리별 발견

### 1.1 Broken endings — **0 발견**

Phase 4 commit `b866349 fix(narrative): iter4 prose-read repair (semantic +
broken endings)` 와 `2d8b068 fix(brief): enforce <=28 ko chars` 가 깨끗하게
정리한 것으로 보인다. `~다.` 의 dangling stems, `,` for end-of-string,
bracket mismatch, `유의해져` artifact 모두 0건.

> **주의**: 초기 audit 은 brief 의 `결이에요.` 종결을 broken-ending 으로
> 보고 43 건을 surface 했지만, 이는 의도된 design 이다.
> `template-engine.ts:727-748 compressBriefHeadlineIfApplicable` 가
> 28 ko 초과 시 `흐름이에요 → 결이에요` 로 reverse 한다.
> Phase 3 의 hard contract `brief.headline ≤ 28 ko` 를 만족하기 위한
> 의도된 후처리. 본 audit 의 `briefCompressionGyeol` diagnostics
> counter 로 **43건** 추적함 (issue 아님).

### 1.2 Voice 위반 (~다 plain-declarative endings) — **0 발견**

`해요/예요/이에요` 친근체 doctrine 일관성 OK. brief, standard, expert,
legacy 4 depth 모두에서 `한다 / 된다 / 간다 / 본다` 등 bare 다 종결 0건.

`~ㅂ니다 / ~습니다` 폼은 73 건 (`쉬워집니다`, `자라납니다`, `살아납니다`,
`넓어집니다`, `깊어집니다`) 발견되었으나 이는 합쇼체 (정중-격식체) 로,
NARRATIVE_STYLE_GUIDE 의 `tone="여유로운/격조있는"` 에 부합. `~다`
declarative 가 아닌 `~ㅂ니다 (verb-stem + ㅂ + 니 + 다)` 정중체이므로
음성 위반에서 제외했다.

### 1.3 Cross-element metaphor mix — **66 surface, ~5-10 의심 (heuristic)**

OFF-AXIS 원소 metaphor 가 한 cell 에 3+ 종 등장하는 경우를 surface 했다.
실제 분포:

```
EARTH+METAL+WOOD       38건  (대부분 false positive)
EARTH+WATER+WOOD       24건  (대부분 false positive)
FIRE+WATER+WOOD         3건  (검토 필요)
EARTH+FIRE+METAL+WATER+WOOD  1건 (audit 필수)
```

대부분 false positive 인 이유: "다듬다 (METAL)", "쌓다 (EARTH)",
"자라다 (WOOD)" 등이 일반 동사로 쓰일 때 element token 으로
오인식 함. 진짜 metaphor mix 의심 fragment 는 **5-10 건** 추정 (수동 review 필요).

**audit-findings.json 의 `crossElementMetaphor` 배열 참고**.
