## Headline

`ci:flow-cluster` instantiates the P14-A5 / P15-A4 cluster lock as a CI
gate so any future fragment-pool or post-processor change that
reintroduces 3+ `흐름이` occurrences in a single rendered paragraph
fails fast.

The gate caught the existing P28-A2 → P28-A6 regression on first run:
**violationCount = 15** (10 cells from `overall.life.expert.strong.neutral.005`,
5 from `family.life.expert.young_caregiver.008`). This matches P28-A6's
reported "flowCluster 0 → 15" exactly, confirming algorithmic faithfulness
to `artifacts/phase15-agent-a4/measure_p15_a4.mjs`. P29-A1 reverts the
two regressed fragments; once that lands and samples regenerate, the gate
will report 0 violations.

## Lineage

The cluster pattern was first identified in **P14-A5 §B3** as a
mechanical-template signature: a single `흐름이` repeating 3+ times in
one paragraph reads as templated narrative rather than situated fortune
text. The pattern is sometimes valid in parallel-construction contexts
(coordinated `A의 흐름이 ..., B의 흐름이 ...`) but at threshold ≥ 3 in a
single paragraph it almost always signals fragment authoring that leaned
on `흐름이` as a connective filler word.

**P15-A4** measured the baseline (51 cells across 7 fragment IDs in
`artifacts/phase15-agent-a4/baseline-cluster.json`) and drove the count
to 0 by reworking 5 source fragments (`after-all-fixes.json`). The
detector lived in `artifacts/phase15-agent-a4/measure_p15_a4.mjs` as a
one-shot measurement script. The lock was data-only; there was no
structural enforcement.

**P28-A2** extended `expert` tier from 4 paragraphs to 5 paragraphs on
10 fired cells (commit `c658dc5b`). The new 5th paragraph in
`overall.life.expert.strong.neutral.005` and the new 5th paragraph in
`family.life.expert.young_caregiver.008` each contained 3 occurrences
of `흐름이`. Because no CI gate locked the P15-A4 invariant, the
regression slipped through 18-gate acceptance and was only discovered
by **P28-A6** as part of the final integrated audit (sample regen plus
ad-hoc cluster scan).

**P29-A1** reverts the regression by rewording those two paragraphs.
**P29-A2** (this gate) makes the lock structural so the next regression
fails fast at PR time.

## Algorithm

The detection logic is a verbatim port of
`artifacts/phase15-agent-a4/measure_p15_a4.mjs` lines 30-115. Specifically:

```
walk artifacts/sample-outputs-2026-05-05-phase3/*-tiered.json
  for each fixture file matching /-tiered\.json$/:
    skip if no payload.tieredMatrix.periods
    for each periodKey in tieredMatrix.periods:
      cells = [['overall', period.overall], ...byCategory entries]
      for each (catKey, cell):
        for each tier in {brief, standard, expert}:
          paragraphs = [cell[tier].headline] +
                       cell[tier].paragraphs[].plainText
                       (or paragraphs[].text legacy fallback)
          for each paragraph p:
            c = countOccurrences(p, '흐름이')
            if c >= 3:
              record cluster paragraph
              if cell not yet recorded as violator:
                record cell as violator (with first-paragraph excerpt)
```

`countOccurrences` is a non-overlapping substring count (`indexOf` walk
with stride = needle length). Since `흐름이` is 3 characters and never
overlaps with itself, this is equivalent to a literal count.

## Violation denominator

The gate counts **cells** as the violation unit, not paragraphs. P28-A6
reported "flowCluster 0 → 15"; that 15 is `cellsWithClusterCount` from
the P15-A4 measurement script. Using cells preserves continuity with the
prior P15-A4 / P28-A6 reporting and matches the natural fragment-source
attribution: a fragment is shipped per cell, so a fragment fix is a
per-cell remediation. The JSON report still emits `paragraphsWithCluster`
for diagnostics. Today the two numbers coincide (every cluster cell has
exactly one cluster paragraph), but the gate keeps them distinct for
future shapes where one cell could surface multiple cluster paragraphs.

## CLI shape

The gate follows the convention established by `check_standard_paragraph_floor.mjs`
and `check_brief_tier_placeholder.mjs`:

- `node tools/check_flow_cluster.mjs` — human-readable summary,
  exits 0 if violations ≤ `--max-violations`, else exits 1.
- `node tools/check_flow_cluster.mjs --json` — structured JSON
  report on stdout.
- `--max-violations=N` — the lock threshold (default 0; package.json
  pins this at 0).
- `--threshold=N` — `흐름이` occurrences per paragraph that constitute
  a cluster (default 3 — P14-A5 / P15-A4 definition; intentionally
  configurable so future analyses can compare against different
  thresholds without code changes).
- `--needle=<str>` — the cluster needle (default `흐름이`; same
  rationale).
- `--root=<path>` / `--samples-dir=<path>` — same overrides as
  sibling gates.

`package.json`: `"ci:flow-cluster": "node tools/check_flow_cluster.mjs --max-violations=0"`.
