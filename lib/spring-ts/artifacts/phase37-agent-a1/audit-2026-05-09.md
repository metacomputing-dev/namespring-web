## Insertion mode (per fragment)

Two modes used, chosen per existing P3 structure:

- **insert-P3** (3 fragments): existing P3 is a single short
  closing aphorism (36–64 chars) — new substantive paragraph
  inserted between P2 and the existing P3, which becomes P4.
  Matches P25-A2 / P26-A2 / P29-A4 / P31-A4 / P32-A2 / P33-A2 /
  P34-A1 / P35-A2 / P36-A1 lineage.
- **append-P4** (2 fragments): existing P3 is already substantive
  (75–85 chars) — new paragraph appended as P4. Matches P26-A3 /
  P30-A1 / P31-A4 / P32-A2 / P33-A2 / P34-A1 / P35-A2 / P36-A1
  substantive-tail pattern.

The 3/2 split is different from P36-A1's 2/3 and P35-A2's 4/3 —
driven entirely by each fragment's existing P3 content, so the
distribution falls out of the data rather than being engineered.

## Per-paragraph spec

Per task constraints + P29-A4 / P31-A4 / P32-A2 / P33-A2 / P34-A1 /
P35-A2 / P36-A1 distilled lessons:

- **96–107 chars** (within standard window; this batch ranges
  96, 97, 100, 107, 107)
- **흐름이 = 0** in source per paragraph (post-processor `흐름`
  budget = 2 → rendered ≤ 2; flow-cluster threshold = 3 stays clear)
- **결 = 0** in source per paragraph (avoids
  `reduceOverusedGyeol` substitution → `흐름X` clustering risk;
  P29-A1 / P30-A1 / P31-A4 / P32-A2 / P33-A2 / P34-A1 / P35-A2 /
  P36-A1 lesson, especially critical this phase since
  `ci:gyeol-cluster` is at the 10-violation hold threshold)
- sentence-final 요-endings (~줘요/져요/돼요/예요/세요/아요/워요/etc.)
- no jargon (신강/신약/격국/십성/용신/etc.) — standard tier
- no axis/gating/livingTips/cautions/sourceTier change
- pure `templateTokens[0].value` edit only

산길-고갯마루). P36-A1's metaphors (도예가-흙, 우물물-마당), P35-A2's
