Two findings dominate this audit:

1. **Two `_coverage/` source occurrences of `연결+vulnerable particle`
   were missed by P18-A5's 7-pattern table.** P18-A5 substituted on
   `[을이로은의도만]` but its scan missed `입니다` (the post-processor's
   `결입니다 → 흐름입니다` rule, GYEOL_SUBS line 765 in
   `src/report/tiered/template-engine.ts`). The current main has:
   - `_coverage/yongshin-action-density.fragments.json:22` —
     `… 성장, 배움, 연결입니다.` (vulnerable; emit will mangle to `연흐름입니다`)
   - `_coverage/age-phase-focus-density.fragments.json:470` —
     `… 편안한 연결과 안전한 환경 …` (NOT vulnerable; `과` ∉ GYEOL_SUBS)
   - `_coverage/birth-winter-current-season-pairs.fragments.json:151` —
     `… 작은 연결과 작은 실행 …` (NOT vulnerable; `과` ∉ GYEOL_SUBS)
   The current sample regen still emits 2 raw `연흐름` strings (in
   `14-choi-palace-naeum-surface`, `25-jonggyeok-jonggwan`,
   `35-palace-naeum-female-mid` per
   `pre-fix-snapshot-2026-05-07.json`). One of these traces back to the
   `_coverage/yongshin-element-daily-support` fragment (now post-fix in
   the source — `연결고리를`); the leak in samples reflects stale
   regeneration, not a live source bug for that cell. The other 2 raw
   `연흐름` cells trace to `_coverage/age-phase-expert-mature` (already
   `연결고리를` in source) — pure stale-sample drift from P18-A5's
   incomplete regen of post-P18-A5-source state. These will clear on
   the next `samples:regen` invocation.

2. **The doubled `결이` cluster reopened: 11 `brief.headline` cells
   carry `사람과의 결이 차분히 정돈되는 결이에요`.** P18-A4 added a
   cluster-aware guard inside `compressBriefHeadline` to skip reversal
   candidates that would form a `결X … 결X` brief. The fix landed on
   main (`fae5a93`); the 11 cells come from the post-processor's
   `흐름이에요 → 결이에요` reversal firing on a base headline that
   already contained `결이` from a prior `흐름이 → 결이` reversal in the
   same chain. The pre-fix snapshot now reads 11 (P18-A4 was 0). Since
   no src change has hit main between `fae5a93` and HEAD `dba1848` that
   would regress this, the 11 cells are likely caused by sample drift
   exposing a regression in the `흐름이에요 → 결이에요` ordering — the
   doubled-`결이` cluster guard appears to compare against the BASE
   headline (pre-substitution), not the running output. A definitive
   diagnosis is out of scope for this audit; logged as a P19+
   investigation for the src-scope owner.

## Phase 19 issues observed

### I1. `ci:samples-stale` regen-drift cycle re-opened (15 stale)

The 4-consecutive-catch cycle that P18-A5 closed (P14-A5 33 → P18-A5 0)
has re-opened with 15 stale samples. Two upstream causes:

1. P18-A5's source rephrasing (`연결X → 연결고리X`) for two cells
   (`yongshin-element-daily-support`, `age-phase-expert-mature`) was
   regenerated to samples 84cc56e), but two specific cells in
   `14-choi-palace-naeum-surface`, `25-jonggyeok-jonggwan`,
   `35-palace-naeum-female-mid` re-introduced after the regen via
   ordering changes.
2. P19-A1's `overall/life/branching.fragments.json:147` data fix
   (`99eb2a1`) was committed without a follow-up `samples:regen`; the
   13 fixtures touched by `livingTips` for `overall.life` will all
   regen-diverge until a regen is included.

Resolution: the next P19 PR (any of A1 / A2 / A3 / A4) that lands data
or src changes must include `npm run samples:regen` before commit. The
P19-A4 PR is a candidate since it adds a sample-reading gate.

### I2. P18-A5's 7-particle table missed `입니다`/`이에요`/`이라`/`이고`/`은`/`처럼`/`마다`

P18-A5 audit doc §A.1 enumerated 8 particle forms (을/이/로/은/이/만/도/의)
which collapses to 7 distinct forms (it omitted the duplicate `이`
listing). P18-A5's substitution missed:

- `결입니다` (P18-A5's commit message lists "8-pattern" but the table
  in audit §A.1 missed `입니다`)
- `결처럼`, `결마다`, `결이에요`, `결이라`, `결이고` (longer particle
  forms; rare in `_coverage/` but possible)

The current `_coverage/yongshin-action-density.fragments.json:22`
contains `… 성장, 배움, 연결입니다.` — exactly the missed form.

P19-A1's owned scope explicitly says "8 compound 패턴" and the plan §1
lists `을/이/로/의/에/과/도/만`. Neither `입니다` nor any of the longer
particle forms are in this scope. **Recommendation P20 #1**: extend
P19-A1's pattern list to include the full 13-form GYEOL_SUBS set
(이/을/로/은/의/도/만/처럼/마다/이에요/입니다/이라/이고) before
ratifying the post-Phase-19 acceptance.

### I3. `ci:acceptance-completeness` is in transient FAIL state

A4's `package.json` adds `ci:hook-coverage` script. The script tool is
new (`tools/check_hook_coverage.mjs`). The acceptance manifest at
`tools/acceptance-manifest.json` has not yet been updated to include
this script in `accepted[]` or `exempt[]`. The gate fails with
`ci_gate_undeclared`.

Resolution: A4's PR must include the manifest update. This is a
self-contained 1-line edit; flagged for A4 reviewer attention.

### I4. Doubled `결이` cluster regression (11 cells)

P18-A4 added a cluster-aware guard to `compressBriefHeadline`. Per the
P18-A4 commit message (`fae5a93`), the cluster `사람과의 결이 차분히
정돈되는 결이에요` was the original target. Current pre-fix snapshot
shows 11 cells with **the exact P18-A4 target string** — same surface,
same fixture group. This is a regression *of the same exact bug* that
P18-A4 closed.

The most likely cause is a chain-application bug: P18-A4 guards the
specific `흐름이에요 → 결이에요` candidate, but the fix may
short-circuit before the `흐름이 → 결이` reversal in the prior chain
applies, or the guard checks against the post-substitution running
output rather than the cumulative running output. Diagnosis requires
looking at `BRIEF_HEADLINE_REVERSALS` ordering and
`compressBriefHeadlineIfApplicable` execution order, both src-scope.

**Recommendation P19+ #2**: src-scope owner re-investigates the
guard's running-output comparison.
