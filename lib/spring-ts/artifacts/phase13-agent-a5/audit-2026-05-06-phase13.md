## Issues fixed this phase

### A. Production gate `ci:narrative-orphan-tags` violations (2 fragments, 4 token splits, 2 tags additions)

The `tools/check_orphan_tag_text.mjs` gate (wired by P12-A3 as
`ci:narrative-orphan-tags`) found 2 violations at HEAD that P12-A5
acceptance did NOT include:

| File | Fragment | Bare lead-in | Sibling tagged form |
|------|----------|--------------|---------------------|
| `academic/thisWeek/expert.fragments.json` | `academic.thisWeek.expert.aligned.002` | `이번 주는 일진의 흐름이 ` | `_coverage/min14-academic-floor.fragments.json :: academic.thisWeek.expert.focus.501` has `#일진의 흐름이` |
| `academic/thisWeek/expert.fragments.json` | `academic.thisWeek.expert.conflicting.003` | `이번 주는 일진의 흐름이 ` | (same) |

#### Detector contract (production gate)

A bare `<label>의 <stem>` match is a violation iff (a) some sibling
fragment in the axis cohort renders the SAME `(label, stem)` key as
a tag (`#<label>의 <stem>`), AND (b) the offending fragment itself
does not already use `<label>` as a tag elsewhere — the latter is
the "intentional Korean re-mention" carve-out documented by P11-A5.

Both fragments here have:
- bare key: `(일진, 흐름)`;
- sibling tagged key in same axis: `(일진, 흐름)` from
  `_coverage/min14-academic-floor.fragments.json`;
- own `tags` array: lacks `iljin` entirely (no carve-out applies).

#### Why P12-A5 missed this

P12-A5's curated detectors (six in `audit-phase12.mjs`) and the
sibling-axis residual detector `find-orphans-residual.mjs` are
narrower than the production gate:

- `find-orphans-residual.mjs` requires `fragmentTagLabels.has(label)`
  (the offending fragment must ALREADY tag the label elsewhere) — i.e.,
  catches re-mention regressions only. fragments .002 and .003 do
  not tag `iljin` at all, so this detector skipped them.
- The production `check_orphan_tag_text.mjs` requires the OPPOSITE:
  `!b.item.fragTagLabels.has(b.label)` (the offending fragment must
  NOT tag the label elsewhere) — catches intro-as-bare-text regressions.
  These two detectors are complementary; they cover orthogonal defect
  categories.

P12-A5's audit doc (lines 31-38) listed 7 acceptance gates but omitted
`ci:narrative-orphan-tags`. The P12-A4 academic commit (`e8c029f`)
introduced or surfaced these 2 violations: rewriting wildcard.001's
closing changed the sibling-axis stats; the gate started flagging .002
and .003 once min14-academic-floor's `#일진의 흐름이` paired with their
bare `일진의 흐름이`.

Verified by bisect:
- At commit `c518cf6` (P12-A3 wiring): production gate → 0 violations.
- At commit `e8c029f` (P12-A4 academic closings): production gate → 2 violations.
- At HEAD (before P13-A5 fix): production gate → 2 violations.

#### Fix shape

Both fragments fixed identically (data, not src):

```diff
       "templateTokens": [
         {
           "kind": "text",
-          "value": "이번 주는 일진의 흐름이 "
+          "value": "이번 주는 "
+        },
+        {
+          "kind": "tag",
+          "tagId": "iljin",
+          "label": "일진"
+        },
+        {
+          "kind": "text",
+          "value": "의 흐름이 "
         },
```

And `tags` array gains `"iljin"`:

```diff
       "tags": [
+        "iljin",
         "yongshin",
         "heeshin",
         "sikshin",
         "jeongin"
       ],
```

Rendered text changes from `이번 주는 일진의 흐름이 #용신·#희신의 결로...`
to `이번 주는 #일진의 흐름이 #용신·#희신의 결로...`. Reader-meaning is
preserved; tag-glossary surface gains 1 reference per fragment selection.

## Issue categories (new this phase)

### B1. CI-acceptance-curation gap

P10-A5 / P11-A5 / P12-A5 audit acceptance lists were curated subsets
of the available `ci:*` gates. P12-A5 listed 7 of the 9 narrative gates
plus typecheck, no-ai-policy, and 2 tests; `ci:narrative-orphan-tags`
(wired by P12-A3) was not in that list. Result: a violation that
crossed the gate was not caught at P12-A5 acceptance time.

P13-A5 acceptance lists ALL 9 narrative `ci:*` gates explicitly. This is
the meta-lesson and is recommended as default for Phase 14+.

### B2. Sample regen drift

When a `data(narrative)` change crosses fragment boundaries (e.g.,
P12-A1's `의 결과` → `의 흐름과` rewrite touching 68 files), the
sample regen MUST run after that commit, not just after the most
recent commit in the topic. Otherwise samples report stale content
that misleads downstream consumers (e.g., FRONTEND_EXTENSIONS
showcase, manual review). P13-A5's catch-up regen demonstrates
3.6K line-equivalents of drift accumulated over 3 phases.

### B3. `usedInThisReport` test count varies (informational)

`test:namespring-compat` PR-Q-27 outputs
`tieredMatrix.glossary.entries covers used report tags (N/N)` where
`N` ranges 54–58 across 5 consecutive runs at HEAD. The assertion
`entries.length === usedGlossaryCount` always passes (both vary
together). Cause: `engine.getFortuneReport(...)` defaults `targetDate`
to `new Date()` (`src/spring-engine.ts:2873`); fragment selection is
date-keyed, so different test-run wallclocks select different fragment
combinations. Not a defect (assertion robust). Worth noting because
audit-time output capture loses information unless multiple runs are
recorded.

## Recommendations for next phase

### High priority

1. **Phase 14 — Acceptance-gate-list standardization.** Make `ALL`
   `ci:narrative-*` + `ci:no-ai-policy` + `typecheck` the default
   acceptance list for every P*-A5 audit. The mechanism that should
   enforce this: a `tools/check_acceptance_completeness.mjs` (or
   equivalent CI step) that diffs the listed gates in audit docs
   against `package.json scripts ci:*` and fails on omission. P13-A5
   identified this gap from a single missing gate (`ci:narrative-orphan-tags`)
   and wants Phase 14 to make this systemic.

2. **Phase 14 — Sample regen byte-stability gate.** Wire a
   `ci:samples-stale` gate that runs `generate-samples.ts` to a
   tempdir and diffs against `artifacts/sample-outputs-2026-05-05-phase3/`
   modulo `generatedAt` timestamps. Threshold: 0 differences. This
   prevents the P12-A1 → P12-A5 drift pattern.

### Medium priority

3. **Phase 14 — Decide `brief.hook` schema fate.** Either:
   a. Implement hook rendering (add `hookSlot` author surface,
      `compose()` pipeline emits `BriefFortuneText.hook`, contract
      test asserts non-empty hook for ≥ N brief cells).
   b. Drop `BriefFortuneText.hook?` from `src/report/types.ts` and
      `NarrativeFragment.hookSlot?` from the fragment registry.
   The third year of this hanging is overdue. (Carry-over from P12-A5 §3.)

4. **Phase 14 — Audit `template-engine.ts` post-processor cluster
   triggers.** The `결이 → 흐름이` chain at line 686 is a global
   rewrite; consider sentence-aware variants that don't trigger when
   the result would produce 3+ `흐름이` in close proximity. P12-A5
   used data-side rewording as a workaround; src-side fix is cleaner.
   (Carry-over from P12-A5 §2.)

### Low priority / informational

5. **Detector productionization.** `find-orphans-residual.mjs` and
   `audit-phase12.mjs` could be promoted to `tools/` and wired as
   gates. They've each found ≥ 2 issues across the last 2 phases;
   that's productionization-grade signal. (Carry-over from P12-A5 §5.)

6. **Tightening the `흐름이` over-cluster detector.** P12-A5 caught
   the top 2 cluster strings. The remaining 13 each impact 1-5
   fixtures. A cluster-aware audit could surface them all and let
   authors decide on rewording. (Carry-over from P12-A5 §6.)

7. **Expert-depth floor variation.** Median expert distinct ratio of
