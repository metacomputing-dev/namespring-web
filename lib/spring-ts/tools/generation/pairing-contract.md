# 페어링 계약 — 평문 ↔ 전문가, 괴리 0 (generation)

> 각 케이스(`case-schema.ts`)는 **한 편의 완결글**로 생성된다. 사용자에게 처음 보이는
> **평문 tier**(summary/hook/body/livingTips/cautions)와, "자세히"를 눌러야 나오는
> **전문가 tier**(expert 문단 + `#{태그}`)는 **같은 사실의 두 표현**이어야 한다 — 괴리 0.

## 1. 두 tier의 관계

- **전문가 tier = 근거(정통 사주명리·성명학 용어 + `#{태그}` + 수치).** 케이스의 강약·용신·격국·
  이름보완을 학술 용어로 서술.
- **평문 tier = 그 근거의 충실한 번역(일반인 언어).** 전문가가 말한 것을 용어 없이 풀어 쓴 것이지,
  별개의 창작이 아니다. 전문가가 "신강이라 재성을 쓴다"면 평문은 "타고난 기운이 단단해 벌이는
  쪽이 맞다"가 된다.

## 2. 불변 규칙 (생성물이 하나라도 어기면 그 케이스는 리젝)

1. **평문 tier에 사주 용어 금지.** 용신·격국·십성·재성·정관·신살·득령·원형이정 등 금지
   (게이트 `SAJU_JARGON_GENERAL`). 오행 **이름**(나무·불·흙·쇠·물)·평문 형용사는 허용.
2. **전문가 tier만 용어·`#{태그}`.** 태그는 2~6개, 글로서리에 존재하는 id만.
3. **모순 금지.** 평문의 주장과 전문가의 주장이 어긋나면 안 됨. 특히:
   - 강약 방향 일치: 신강 케이스면 평문·전문가 둘 다 '쓰기/발산', 신약이면 둘 다 '채우기/보강'.
   - 용신 일치: 평문이 "부족한 **물**"이라 하면 전문가도 용신=水 계열이어야 함.
   - 이름보완 일치: `nameReinforce=none`이면 평문·전문가 어디서도 "채워 준다"라고 쓰지 않음.
4. **절대 사주상태 단정 완화.** 평문은 조건/서술로("~한 편이라"), 단정 회피.
5. **요약↔본문↔전문가 pairing.** 요약이 약속한 것을 본문이 풀고 전문가가 근거를 댐. 세 층이 한 주제.
6. **미성년 안전**(audienceSafety=minor): 연애·결혼·배우자·투자·보증·전성기·음주·이혼 등 금지.
7. **의료어 금지**: '검진' 등.

## 3. 케이스 축과 문장의 대응

| 케이스 축 | 전문가 tier | 평문 tier |
|---|---|---|
| 강약(gangyak) | `#{신강}`/신약 + 득령·득지 근거 | "타고난 기운이 {단단한/여린/고른} 편이라…" |
| 용신(yongshin) | `#{yongshin}` 오행 = 木/火/… | "채움이 필요한 {나무/불/…} 기운" |
| 이름보완(nameReinforce) | `#{자원오행}`이 용신 보강(combinedDistribution) | "이름이 그 {물} 기운을 {크게/조금/직접 담진 않게}…" |
| 밴드(band) | 기간 오행×용신 조화 등급 | 요약의 톤(잘 풀림/다짐/방어) |

## 4. 검증

`validate-generated.ts`가 각 생성물을 케이스와 대조: 스키마·분량·해요체·평문 용어금지·태그(2~6·글로서리)·
슬롯 유효·미성년 안전·의료어 + **강약/용신/이름보완 방향 정합**. 하나라도 실패 → 리젝·재생성.
