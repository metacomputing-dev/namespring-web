# 원천 근거 사용자 해석 가이드

이 문서는 원천 오행을 사용자에게 납득 가능한 기능으로 풀기 위한 가이드다. 오행이 사람의 성격이나 미래를 바꾼다고 단정하지 말고, 이름이 보태거나 제한하는 작명상의 방향을 설명한다.

## 오행별 사용자 관점 기능

- 목: 새로운 일을 시작하고 꾸준히 성장하는 힘, 가능성을 넓히는 유연성
- 화: 생각과 감정을 표현하고 행동으로 옮기는 힘, 관계에 온기를 더하는 추진력
- 토: 중심을 잡고 일을 안정적으로 이어 가는 힘, 현실을 조율하고 마무리하는 지속성
- 금: 기준을 세우고 필요한 것을 선택하는 힘, 경계와 순서를 분명히 하는 정리력
- 수: 상황을 세심하게 살피고 속도를 조절하는 힘, 변화에 유연하게 대응하고 연결하는 감각

## 해석 원칙

- 실제 렌더링에서는 `{{filledElements}}` 같은 오행명과 `{{filledElementFunctions}}` 같은 사용자용 기능 설명이 함께 제공된다.
- plain에서는 두 값을 연결해 `어떤 성분이 확인됨 → 그 성분이 담당하는 기능 → 그래서 왜 추천에 유리하거나 제한적인지`를 짧게 설명한다.
- 기능 설명을 사전처럼 그대로 나열하지 말고 해당 상태에서 의미 있는 한 가지 효과만 문맥에 맞게 고른다.
- 여러 오행이 들어오면 모든 기능을 억지로 열거하지 말고 공통되는 작명 방향을 중심으로 설명한다.
- `이 성분이 들어오면 추진력이 생겨요`처럼 개인이 실제로 변한다고 단정하지 않는다. `그 방향을 이름에서 받쳐 줘요`, `그 기능을 보완하는 근거가 돼요`처럼 이름 평가의 범위를 지킨다.
- 긍정 상태는 생활상의 장점을 과장하지 않고 왜 필요한 방향인지 설명한다. 제한 상태는 해당 기능 자체가 나쁘다고 말하지 말고, 현재 구조에는 같은 방향이 더해지는 점이 부담임을 밝힌다.
- plain에서는 `기능`, `작용`, `반영`, `판단`, `근거` 같은 계산 언어를 앞세우지 않는다. 오행이 뜻하는 힘을 일상적인 동사로 풀어 쓴다.
- 예를 들어 `금의 기능이 반영돼요`가 아니라 `금 기운이 기준을 세우고 필요한 것을 고르는 힘을 받쳐 줘요`라고 쓴다.
- 긍정 근거는 `무엇이 부족했는지 → 이름이 무엇을 보태는지 → 그 힘이 왜 필요한지` 순서로 설명한다.
- 제한 근거는 `이미 무엇이 충분한지 → 이름에서 무엇이 더해지는지 → 현재 필요한 조절과 왜 거리가 있는지` 순서로 설명한다.
