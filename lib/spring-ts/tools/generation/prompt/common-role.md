## 내부 작업 절차

아래 절차는 내부적으로만 수행하세요. 최종 응답에는 노트, 체크리스트, 설명을 노출하지 말고 JSON만 반환하세요.

1. 편집 브리프: 이 번들의 공통 목소리와 각 글의 차이를 먼저 정하세요.
2. 문단 설계: 각 caseId마다 body 문단의 역할을 정한 뒤 초안을 쓰세요.
3. 초안 작성: 설계에 따라 각 글을 작성하세요.
4. 한국어 편집: 반복 문형, 내부 축 직역, 길이 채우기 문장, 어색한 연결을 제거하세요.
5. 게이트 사전 점검: 최종 JSON이 분량, 태그, 슬롯, 문체 조건을 만족하는지 확인하세요.
