# Narrative Style Guide

> 대상: Phase 2 fragment / glossary 작성자.
> 목표: 11 카테고리 × 5 기간 × 3 depth 텍스트가 한 사람의 목소리로 들리도록.

## 1. 톤 (모든 depth 공통)

- **종결어**: `~해요` / `~에요` / `~이에요`. `~다` / `~한다` 금지 (단, expert tier에서 고전 인용을 명시할 때 예외).
- **호칭**: 사용자 자신을 직접 부르지 않는다 (`당신은` 금지). 대신 행위·상태로 풀어쓰기 (`이 흐름에서 가장 단단해지는 자리예요`).
- **금지 어구**: 명령형 (`~하세요`는 living tips에서만), 지나친 단정 (`~이다`, `반드시`), 불안 자극 (`큰일`, `위험`, `불행`).
- **권장 어구**: 권유·제안 (`~해 보면 좋아요`, `한 번 떠올려 봐요`), 약한 확신 (`~인 편이에요`, `~경향이 있어요`).

## 2. depth 별 contract

### 2-1. `brief` — 1-2 문장 (초·중학생)

- headline: ≤28 한글 자모. 한 줄에 들어와야.
- hook (옵셔널): 보조 한 문장.
- 비유 사용 가능, 어려운 한자어 금지.
- 별점은 텍스트가 아니라 `stars` 필드로 표시. 본문에서 "5점/3점" 같은 직접 언급 금지.

예: `"올해는 재물 흐름이 단단해요."`

### 2-2. `standard` — 3-7 문단 (일반 사용자)

- 한 문단 ~80-160 한글 자모.
- **요청 구조 (권장 5문단)**:
  1. 시기·분야의 큰 그림 (1-2 문장)
  2. 일상 비유로 풀어쓴 이미지 (오행/십성 → 식물·날씨·요리 등)
  3. 강점 (이 시기에 잘 풀리는 것)
  4. 주의점 (피하면 좋을 것)
  5. 마무리 격려
- `livingTips`: 1-3개. 각 ≤24자. 동사로 끝나는 격언풍.
- `cautions`: 0-2개. 약한 어조의 주의 (`~만 줄이면 충분해요`).
- 인라인 태그 금지. 한자어는 한글 풀이로.

### 2-3. `expert` — 4-8 문단 (관심 사용자·전문가)

- 격국·용신·십성 어휘 사용 가능.
- 인라인 `#태그`로 핵심 개념 표시. 문단당 2-6개, 30자당 ≤1개.
- 수치를 인용할 때는 반드시 `numericalEvidence`로 — 본문에 임의 숫자 작성 금지.
- 과도한 단정 금지. `axisStrength` hedge 값에 따라 어조 조절:
  - `definite`: 직설 (`~격이 분명해요`)
  - `practical`: 부드러운 확신 (`~격으로 보여요`)
  - `candidate`: 가능성 (`~격에 가까운 모양이에요`)
  - `deferred`: 보류 (`~격일 수도 있어 추가 단서가 필요해요`)

## 3. 비유 라이브러리

[NARRATIVE_TEMPLATE_DSL.md](./NARRATIVE_TEMPLATE_DSL.md) 의 `slotType: 'elementMetaphor'`가 자동 채움. 직접 작성 시 다음 anchor 사용:

| 오행 | 한 줄 정체성 | 일상 비유 |
|---|---|---|
| 木 (나무) | 자라는, 위로 뻗는 | 새싹, 봄비 맞은 가지, 자라는 화분 |
| 火 (불) | 빛나는, 따뜻한, 표현하는 | 등불, 모닥불, 한낮의 햇살, 깜빡이는 별 |
| 土 (흙) | 단단한, 받쳐 주는 | 들판, 어깨를 기댈 언덕, 잘 다진 흙 |
| 金 (쇠) | 다듬는, 결단하는 | 잘 만든 도구, 가을바람, 정확한 자 |
| 水 (물) | 흐르는, 깊은, 적셔 주는 | 우물, 강물, 호수, 스며드는 빗물 |

비유 1개를 한 fragment 안에서 일관되게 사용. 섞지 않기 (예: 같은 cell에서 木을 새싹과 가을바람으로 동시 비유 금지).

## 4. 성별 modifier

| 차원 | 남성 | 여성 | 중립 |
|---|---|---|---|
| 가족 | `가장으로서`(올드함) → `중심을 잡는` | `엄마/딸로서`(선입견) → `따뜻하게 챙기는` | 위와 같음 |
| 직업 | 단정적 직업명(예: 의사) 금지 | 동일 | 동일 |
| 연애 | "이성"보다는 "짝", "인연" | 동일 | 동일 |

원칙: **성별로 가능성 좁히지 않기**. 성별 표현은 표면적 어휘만 (`아빠/엄마`처럼 가족 안 호칭) 차이.

## 5. 연령대 modifier

| 연령대 | 핵심 톤 |
|---|---|
| 0-9 | 보호자가 함께 읽는다고 가정. 3인칭 ('아이는'). 추상보다 행동 (`달리고 싶은`). 진로·연애 미언급. |
| 10-19 | 친구 같은 어조. 학업·관계 비중. 직업·결혼 단정 금지. |
| 20-29 | 도전·시작. 현실적 첫 결정. 선택지 제시형. |
| 30-39 | 균형·확장. 가족·일·자기 사이의 조정. 장기 관점 등장. |
| 40-54 | 단단함·재정비. 책임 큰 자리. 건강 신호 시작. |
| 55-69 | 정리·전환. 후반기 흐름 도입. 가족 다음 세대 언급 가능. |
| 70+ | 풍요·여유. 결실. 건강은 따뜻하게. 무리·초조 어휘 회피. |

연령대별 어휘 변형은 `slotType: 'ageLabel'` 으로 자동 노출. 본문에서 직접 언급 시는 위 톤을 따른다.

## 6. 카테고리 voice

| 카테고리 | voice 한 줄 |
|---|---|
| `overall` | 큰 그림, 격려, 종합 |
| `wealth` | 재물·관리·기회. 두려움 자극 X |
| `health` | 따뜻함, 일상 팁 비중. 의학 단정 X |
| `academic` | 시험·시기. 무리·압박 X |
| `romance` | 인연·관계. 결혼 단정 X |
| `family` | 가까운 사람·뿌리. 비교 X |
| `career` | 자리·책임. 직장 폄하 X |
| `study_document` | 시험·자격·서류. 합격 단정 X |
| `expression_children` | 표현·자녀. 무자녀 단정·강요 X |
| `health_stress` | 스트레스·휴식. 진단·약 단정 X |
| `movement` | 이동·변화. 거주지·국적 단정 X |

## 7. 금기

- 의학·법률·재무 직접 처방 금지 (`먹어야 한다`, `소송하라`, `~주식 사라` 등).
- 사망·이별 시기 단정 금지 (`~년에 헤어진다` 등).
- 종교 권유 금지.
- 다른 사람을 흉보는 어조 금지.
- 사주 외 다른 점술 (타로·관상 등) 단정 금지.

## 8. 검수 체크리스트

작성 후 self-check:
- [ ] depth contract 부합 (brief 1-2문장, standard 3-7문단, expert 4-8문단)
- [ ] 종결어 `~해요`체
- [ ] 비유 1개 일관
- [ ] 성별·연령대 modifier 적용
- [ ] 금기 어구 0개
- [ ] expert tier만 #태그 사용, glossary에 존재
- [ ] livingTips/cautions 길이 ≤24자
