# Academic 생성 프롬프트 개선안 (카테고리 스코프)

> 대상: `academic` 분야 생성 텍스트(`data/generated/academic/`)
> 변경 파일: `tools/generation/bundle-prompt.ts` — `buildBundlePrompt()`에 academic 전용 지침 블록 추가.
> 범위: **academic 한정.** 다른 카테고리(romance·family·health 등)는 프롬프트가 바이트 단위로 동일 — 무영향.
> 관련: `PLAN_PR1_GENERATED_TEXT_QUALITY.md`, `S3_CONTINUATION_PLAYBOOK.md`, `pairing-contract.md`.

---

## 1. 배경

파일럿(`academic.adult.balanced.bigeop.boost_strong.x`, 15편)을 유료 사용자 관점으로 검수한 결과, 게이트는 통과하지만 유료 리포트로서 두 축이 약했다.

- **이름효과 실종**: 사람 조건이 "이름 크게 보강(strong)"인데, 이름 앵커가 expert(사주 용어 포함, 일반 독자 미열람)의 일부 편에만 존재. body/summary에는 전무 → strong 조건이 독자에게 전달되지 않음.
- **학업 이벤트 부재**: 자료 정리·필기·자리 배치 같은 일반 공부 습관 위주. 시험·자격증·강의·복습이 없어 "무료 블로그 공부팁"으로 읽힘.
- **추상어·문형 반복**: "배움에 힘이 실려서"류 은유가 15편 도입부를 지배, 등급별 오프닝 공식이 반복.
- **cautions가 "하지 마세요"형**: 왜 조심해야 하는지(결과)가 약함.

## 2. 변경 요약 — academic 전용 지침 블록

`buildBundlePrompt()`에서 `c0.category === 'academic'`일 때만 프롬프트 말미에 다음 지침을 주입한다(그 외 카테고리는 빈 문자열).

1. **body = 학업운 해석(3문단 구조)**: ①이 시기에 공부가 어떻게 느껴질 수 있는지+맞는 단위(단정 금지, 조건부 관찰형) ②구체 공부 사용법 ③무리 지점과 조절법.
2. **이름효과를 body 1·3문단에 1회, 비단정형으로** — expert 독점 해소. 또한 **이름효과의 의미를 기간별로 분화**(오늘=한 세션 매듭 / 이번주=요일 리듬 지속 / 이번달=한 과목 완주 / 올해=상반기 방향 설정 / 평생=축적).
3. **학업 이벤트 기간별 필수**: 시험·자격증·강의·복습·발표·제출·업무 학습.
4. **추상어 상한**(흐름·기운·힘·결·바탕·잔잔) — 은유 오프닝 반복 금지.
5. **비겁 변별**: 동료 모티프 남용 금지, 경쟁·자기주도 점검·기록 비교로 분산.
6. **body 안전 표현 사전**(~하기 쉬운 편이에요 / ~수 있어요 …) + 금지 표현(학업운이 강해서/약해서, 반드시·확실히, 합격·성공 단정).
7. **cautions 인과형 공식**: "[트리거]하면 [학습 리듬/결과]가 [흐려질/흔들릴/줄어들] 수 있어요". 학습 행동어 1개 포함, 하드 44자.

근거 상세: `academic_sample_docs.md`(단정 회피 문법·안전 표현·cautions 공식).

## 3. 게이트 충돌 처리

두 지점이 게이트(no-absolute-assertion, 길이)와 부딪혀 다음과 같이 해소했다.

- **"학업운 작동"을 단정하지 않기**: "학업운이 강해서 잘 됩니다"는 리젝. → "직접 고른 과제 하나에 집중이 붙기 쉬운 편이에요" 같은 **조건부 관찰형**으로.
- **cautions 길이**: "[트리거]하면 [결과] 수 있어요"를 44자 이내로 고정.

## 4. 전/후 검수 결과 (독립 검수, 9축 1~5점)

동일 번들을 3회 재작성하며 독립 검수로 채점.

| 항목 | v1(개선 전) | v2(1차) | v3(2차) |
|---|---|---|---|
| 1. 바로 이해 | 4 | 5 | 5 |
| 2. 추상어 억제 | 2 | 3 | 4 |
| 3. 15편 반복 억제 | 2 | 3 | 3 |
| 4. tips/cautions | 4 | 5 | 5 |
| 5. "내 얘기" | 3 | 4 | 4 |
| 6. 클래스 내 변별 | 3 | 3 | 4 |
| 7. 이름효과 앵커 | 2 | 4 | 5 |
| 8. 기간별 전략 | 4 | 5 | 5 |
| 9. 학업 이벤트 | 3 | 5 | 5 |
| **평균** | **3.0** | **4.1** | **4.44** |

- 하락 항목 0. 8/9 항목이 4~5점. 검수 총평: "유료 적확함에 사실상 도달."
- 게이트: 전 버전 dry-run **15/15 통과**. academic 블록 추가 후에도 유지.

## 5. 방법론 (재현 가능)

`생성 → ingest-bundles.ts --dry-run 게이트 → 독립 검수(9축) → 지침 반영 → 재생성` 루프. 카테고리 스코프 블록이라 통과율 튜닝을 카테고리별로 독립 진행할 수 있다.

## 6. 남은 과제 (v4 후보)

- **항목 3(반복, 3점 정체)**: 이름효과의 *의미*는 기간별 분화됐으나 *문장 프레임*("이름이 보태는 배움은 A 때보다 B 때 ~")이 15편 동일 → 코퍼스로 읽으면 보일러플레이트. **문장 틀 3~4종 로테이션**(도치/부정/조건형) + low 안심구 표현 풀 로테이션으로 3→4~5 진입 가능.

## 7. 팀 결정 필요

- 이 블록은 카테고리 스코프이므로 **다른 분야 통과율에 영향 없음**. academic 확장 생성에 바로 사용 가능.
- 동일 방식(카테고리 전용 블록)을 romance·family 등에 개별 적용할지는 각 분야 검수 결과를 보고 결정.
