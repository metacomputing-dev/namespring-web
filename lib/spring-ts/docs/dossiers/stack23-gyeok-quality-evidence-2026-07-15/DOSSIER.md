## 결론

일반 월령격의 **선택 후보 집합**과 **품질 판정을 위한 투간 증거 집합**은 서로 다른
책임을 가진다. 비견·겁재 후보가 일반격 선택에서 제외되더라도 실제로 투간했다면
순도(`purity`), 혼잡 여부(`mixed`), 청탁(`clarity`)의 관측 증거에서는 사라지면 안 된다.
두 집합을 같은 filtered 배열로 사용하면 노출 겁재가 있는데도 `mixed:false`와
`PAGYEOK/GEOB_JAE`가 동시에 나오는 내부 모순이 생긴다.

이 구조 모순은 현재 `main`의 `4426696af`에서 수정됐고, 토 잡기월과 선택 격 자체를
품질 증거에 포함하는 후속 경계는 `b50afea15`, `f14566c1e`에서 보강됐다. 원래 스택 23의
동일 방향 패치를 다시 적용하지 않은 이유는 현재 구현이 더 엄격한 상위 버전이기 때문이다.

다만 구조적 일관성이 확보됐다는 사실은 현행 purity/clarity 계수나 각 격의 명리적
정당성이 외부 전문가에게 승인됐다는 뜻이 아니다. 그 검토는 certified release 차단선으로
계속 남는다. 반면 이 문서 전용 PR은 판정 코드를 바꾸지 않으므로 증거를 보존하기 위한
점진적 backend merge를 막지 않는다.

## 역사적 결정론 표본

원래 비교는 base `3011d1904bfe71c7005e234b4c0698b41dc686fb`와 변경
`290b669a7` 사이에서 수행했다. 난수나 실제 출생 분포가 아니라 합법 간지 조합의 균일
격자에서 `linearIndex % 101 === 0`인 항목을 선택했다.

| 항목 | 건수 | 표본 대비 |
|---|---:|---:|
| 전체 표본 | 5,133 | 100% |
| 선택 제외 visible companion 증거 존재 | 358 | 6.9745% |
| 품질 결과 변화 | 126 | 2.4547% |

126건은 편관 17, 편재 10, 식신 14, 정재 11, 편인 21, 상관 12, 정인 26,
정관 15건이다. 합계는 126이다.

이 비율은 실제 사용자 발생률, 인구 유병률, 시장 영향률 또는 통계적 추정치가 아니다.
당시 기본 17개와 격국 후보 261개 snapshot은 모두 무변이었으므로, 고정 fixture 밖의
영향을 별도 표본으로 드러낸 자료다.

## 현재 구현과 측정의 관계

- gap과 일반격 선택 자격: 선택 가능한 후보만 사용한다.
- purity/mixed 증거: 선택에서 제외됐더라도 실제 노출된 월지 지장간 후보를 사용한다.
- 선택된 격 자체: 품질 증거 집합에서 누락하지 않는다.
- 토 잡기월: 일반 투간 후보와 구조격을 혼동하지 않도록 별도 경계를 둔다.

후속 커밋이 원래 측정 뒤 경계를 더 보강했으므로 126/5,133은 **역사적 변경량**이다.
현재 코드의 실사용 빈도나 후속 변경 전체의 발생률로 재해석해서는 안 된다.
