# ARTICLE STYLE CONTRACT — 아티클 저작 계약 (spring-ts.article.v1)

> 이 문서는 `data/articles/**`에 들어가는 모든 아티클의 **단일 진실**이다.
> 게이트(`tools/article-quality-gate.ts`)가 이 계약의 수치 규칙을 기계 검증한다.
> 원칙: **저자가 리뷰한 텍스트가 곧 사용자가 읽는 텍스트다.** 런타임 재작성은 없다.

## 1. 글의 목표

유료 리포트의 한 셀(기간 × 카테고리)을 펼쳤을 때 나오는 글 한 편.
독자가 느껴야 하는 것: "잘 쓰인 짧은 칼럼을 읽었다. 내 사주 이야기를 이해했고, 오늘 뭘 하면 되는지 안다."

구조는 항상 4악장(마지막 둘은 합칠 수 있음):
1. **판단** — 이 기간 이 영역이 어떤 모양인지 한 장면으로 제시.
2. **근거** — 왜 그렇게 읽는지, 사주 개념을 일상어로 풀어 설명 (전문용어는 expert로).
3. **적용** — 그래서 무엇을 하면 좋은지, 그 카테고리의 실제 생활 장면으로.
4. **맺음** — 과장도 불안도 없이 균형을 잡아 주는 마무리.

문단은 반드시 **서로 이어지게**: 앞 문단의 끝이 다음 문단의 시작을 예고하거나, 다음 문단이 앞을 받아서 시작한다.
접속은 자연스러운 한국어(“다행히”, “그래서 오늘은”, “한 가지만 조심하면”)로 하고, 기계적 접속사 나열은 피한다.

## 2. 파일/스키마

파일: `data/articles/<category>/<period>.articles.json` (period ∈ life,today,thisWeek,thisMonth,thisYear)
및 `data/articles/<category>/stages.articles.json` (life 연령대 밴드용).

```jsonc
{
  "schemaVersion": "spring-ts.article-bundle.v1",
  "bundleId": "wealth.today",
  "articles": [
    {
      "schemaVersion": "spring-ts.article.v1",
      "articleId": "wealth.today.adult.mid.a",   // <cat>.<period|stage키>.<audience>.<band>.<변형자>
      "category": "wealth",                        // 'overall' 포함 11종
      "period": "today",                           // stages 파일에서도 "life"로 적는다
      "audience": "adult",                         // adult | teen | child | stage-teen | stage-early | stage-mid | stage-senior | stage-elder
      "band": "mid",                               // high | mid | low | any
      "summary": "…",                              // 1문장, ≤60자 → brief.headline
      "hook": "…",                                 // 선택, ≤24자 → brief.hook
      "body": ["문단1", "문단2", "문단3", "문단4?"],  // 3~4문단
      "expert": ["근거 문단1", "근거 문단2?"],        // 1~2문단, #{tagId}·{{슬롯}} 허용
      "livingTips": ["…", "…"],                    // 2~3개, 각 ≤30자
      "cautions": ["…"],                           // 1~2개, 각 ≤44자
      "aiGenerated": true,
      "sourceNote": "article-rewrite-2026-07"
    }
  ]
}
```

- JSON은 UTF-8, 2칸 들여쓰기.
- `articleId`는 전역 유일. 변형자는 a부터.
- stages 파일: `period:"life"`, `audience:"stage-*"`, articleId는 `<cat>.stage-early.any.a`처럼 stage 키를 기간 자리에 쓴다.

## 3. 분량 규칙 (게이트 강제)

| 항목 | 규칙 |
|---|---|
| body 문단 수 | 3~4 |
| body 문단 길이 | 80~240자, 문장 2~5개 |
| body 전체 | 350~800자 |
| expert 문단 수 | 1~2 (각 100~380자) |
| expert 태그 | 2~6개 (`#{tagId}`) |
| summary | 1문장, ≤60자, 해요체 |
| hook | ≤24자 |
| livingTips | 2~3개, 각 ≤30자, 명사형·권유형 |
| cautions | 1~2개, 각 ≤44자 |

## 4. 문체 규칙

1. **해요체 통일.** `~습니다/~합니다` 금지. expert도 해요체(전문성은 내용으로 낸다).
2. **명령형 금지.** "~하세요" 대신 "~해 보세요", "~하는 편이 좋아요", "~해 두면 …해져요".
3. **문장 어미를 다양하게.** 같은 어미("~할 수 있어요", "~좋아요")가 한 문단에 2번 이상 반복되지 않게.
4. **구체어 우선.** 카테고리의 실제 생활 장면(§6 어휘 표)을 쓴다. 추상 명사로 뭉개지 않는다.
5. **은유는 아티클당 최대 1회.** 쓰려면 오행/계절과 자연스럽게 닿는 것 하나만, 한 문장 안에서 끝낸다.
6. **단정 금지·불안 조장 금지, 그러나 물타기도 금지.** "반드시/절대" 금지. 낮은 밴드(low)는
   "위험하다"가 아니라 "속도와 크기를 줄이면 손해가 안 남는다"로. 높은 밴드(high)는
   "다 잘된다"가 아니라 "이 기회를 이렇게 받으면 오래 남는다"로.
7. **별점과 어조 일치.** high=기회를 어떻게 쓸지 / mid=기준 점검과 유지 / low=완급 조절과 회복.
8. **메타 지시문 금지.** "이 해석은 참고용이에요", "하나만 남겨 보세요", "다 읽은 뒤에는" 류의
   읽기 안내 문구를 본문에 넣지 않는다. 글 자체가 안내다.
9. **정보 밀도.** 모든 문단에 그 문단만의 내용이 있어야 한다. 앞 문단을 말만 바꿔 반복하면 실패.

## 5. 금지·상한 어휘 (게이트 강제)

- 상한: `흐름` ≤3회, `기운` ≤3회, `자리` ≤2회, `호흡` ≤1회 (body+expert 합산).
- 금지(0회): 명사 단독 `결`(예: "결이", "결을", "한 결", "결의") — '결정/결과/결실/결론' 등 복합어는 허용.
- 금지 문구: "타고난 중심 기운", "흐름의 색", "자기 격에 맞는", "한 흐름으로", "흐름이 모이는",
  "자리가 자주 등장", "결이 갈라", "점수 해석은", "해석을 덮기 전에", "다 읽은 뒤에는",
  "읽고 난 뒤에는", "하나만 남겨 보세요", "정리하면,", "덧붙이면,", "끝으로,", "쉬운 기준으로 보면".

## 6. 카테고리별 라벨·생활 장면 어휘·미성년 리프레이밍

| category | 셀 라벨 | 성인 어휘(장면) | teen(10-19 본인) | child(0-9, 보호자 독자) |
|---|---|---|---|---|
| overall | 전체 흐름 | 하루/한 주의 리듬, 우선순위, 컨디션과 약속의 균형 | 학교 일과, 시험과 쉬는 시간, 친구 | 아이의 하루 리듬, 잠·식사·놀이 |
| wealth | 돈과 물건 관리 | 고정지출, 구독, 충동구매, 정산, 큰 결제, 계약금 | 용돈 계획, 갖고 싶은 것과 필요한 것 | 용돈·저금통, 물건 아껴 쓰는 습관 |
| health | 몸과 마음 | 잠, 식사 시간, 산책, 카페인, 어깨·허리, 검진 예약 | 수면 리듬, 급식·야식, 체육 후 회복 | 낮잠·이유식/식사, 손 씻기, 열·컨디션 신호 |
| academic | 공부 흐름 | 자격증, 강의, 책 한 권, 정리 노트 | 수업 복습, 오답 정리, 시험 범위 | 그림책, 숫자·글자 놀이, 호기심 질문 |
| romance | 관계와 마음 | 연락 온도, 만남 약속, 마음 표현, 관계의 속도 | 친구 사이의 마음, 서운함 말하기 | 애착, 부모와의 스킨십, 또래와 어울리기 |
| family | 가족 관계 | 양가 안부, 집안일 분담, 가족 식사, 부모님 건강 | 부모님과 대화, 형제와 방·물건 | 보호자와의 루틴, 조부모 방문 |
| career | 진로 감각 | 맡은 일의 마무리, 협업, 이력 정리, 제안 검토 | 진로 탐색, 동아리·발표, 롤모델 | 역할놀이, 칭찬받은 행동, 잘하는 놀이 |
| study_document | 기록과 준비 | 계약서, 증빙, 마감, 백업, 파일 정리 | 알림장·과제 제출, 프린트 정리 | 준비물, 어린이집 가방, 안내문 |
| expression_children | 표현과 창의력 | 글·발표·취미 창작, 결과물 공유 | 발표, 그리기·영상, SNS 표현 | 낙서·만들기, 노래·율동, 감정 표현 |
| health_stress | 긴장과 회복 | 마감 압박, 회식, 혼자 있는 시간, 퇴근 후 루틴 | 시험 긴장, 친구 갈등 스트레스, 쉼 | 낯가림, 칭얼거림 신호, 안정 루틴 |
| movement | 이동과 변화 | 이사, 출장, 여행, 이직 준비, 새 동네 | 등하굣길, 전학·캠프, 새 학원 | 나들이, 카시트·안전, 환경 변화 적응 |

- teen/child 아티클에서 성인 주제(투자, 연애 결정, 이직, 음주 등) 금지.
- **미성년 안전 어휘 게이트(기계 검증)**: audience가 teen/child/stage-teen인 아티클의 모든 텍스트에
  `연애, 결혼, 배우자, 투자, 보증, 전성기, 음주, 술자리, 이혼` 금지 (부정문에서도 금지 — "투자는 하지 않아요"도 불가).
  또한 이 아티클들이 참조하는 태그의 글로서리 정의에 성인 어휘(연애/결혼/배우자/투자/보증)가 있으면 안 됨
  (예: `#{baeujagung}`, `#{cheogung}`, `#{dohwa}`, `#{hongyeom}`은 미성년 아티클에서 사용 금지).
- **미성년 주인공의 생애 밴드**: 엔진이 stage-teen 외 성인 구간 밴드를 placeholder로 비워 서빙한다
  (성인 구간 조언이 미성년 리포트 페이로드에 실리지 않음).
- child 아티클의 독자는 **보호자**: "아이가/아이에게" 시점으로 쓰고, 보호자가 할 일을 제안한다.
- romance의 teen은 '설레는 마음을 다루는 법'까지만, child는 애착·우정으로 완전 리프레이밍.
- stage-* 아티클(생애 밴드)은 주어 중립: "이 시기는", "{{periodLabel}} 구간은" — 특정 나이 독자 단정 금지.

## 7. 슬롯과 태그

### 슬롯 (본문·expert 공용, 최소 사용 원칙)

| 슬롯 | 값 예시 | 비고 |
|---|---|---|
| `{{periodLabel}}` | "오늘 (5월 1일)", "이번 주", "30~39세" | 기간/밴드 라벨 |
| `{{dayMasterName}}` | 나무·불·흙·쇠·물 | 일간 오행 한국어 |
| `{{yongshinName}}` | 나무·불·흙·쇠·물 | 용신 오행 한국어 |
| `{{currentSeasonName}}` | 봄·여름·가을·겨울 | 기준일 계절 |

- 조사 결합: `{{yongshinName:이가}}` → "물이" / "나무가". 지원: `이가` `은는` `을를` `과와` `으로로` `이라라`.
- 슬롯은 문장이 슬롯 없이도 성립할 때만. body에는 0~2개 권장, expert에는 자유(그래도 문장이 주인).

### 태그 (expert 전용)

- 문법: `#{tagId}` — 렌더러가 글로서리 라벨로 치환해 `#라벨` 칩으로 표시된다.
- body(standard)에는 태그 금지 — 일상어로 풀어 쓴다.
- 자주 쓰는 태그: `#{yongshin}`(용신) `#{heeshin}`(희신) `#{gishin}`(기신) `#{johuYongshin}`(조후용신)
  `#{jeongjae}`(정재) `#{pyeonjae}`(편재) `#{jeonggwan}`(정관) `#{pyeongwan}`(편관)
  `#{jeongin}`(정인) `#{pyeonin}`(편인) `#{sikshin}`(식신) `#{sanggwan}`(상관)
  `#{bigyeon}`(비견) `#{geobjae}`(겁재) `#{siksang}`(식상) `#{jaeseong}`(재성) `#{gwanseong}`(관성) `#{inseong}`(인성)
  `#{wood}`(나무) `#{fire}`(불) `#{earth}`(흙) `#{metal}`(쇠) `#{water}`(물)
  `#{dayPillar}`(일주) `#{monthPillar}`(월주) `#{yeokma}`(역마) `#{dohwa}`(도화) `#{munchanggwiin}`(문창귀인)
  `#{hakdang}`(학당) `#{cheonui}`(천의) `#{cheonleulgwiin}`(천을귀인) `#{baeujagung}`(배우자궁) `#{jasikgung}`(자식궁)
- 전체 목록은 `data/narrative/_glossary/*.json`의 `id` 필드. 존재하지 않는 id는 게이트 실패.

### expert 문단의 역할

"이 셀의 판단이 명식의 어디에서 왔는가"를 설명한다. 최소 구성:
- 이 카테고리를 읽는 축(예: 재물 = #{jeongjae}·#{pyeonjae} 균형)을 한 문장으로.
- 이 기간·이 사주에서 그 축이 어떤 상태인지 ({{dayMasterName}}, {{yongshinName}}, {{currentSeasonName}} 활용 가능).
- 그래서 본문 조언이 왜 그렇게 나왔는지 연결.

## 8. 모범 예시 (이 수준이 합격선)

### 8.1 성인 · wealth.today.mid

```json
{
  "schemaVersion": "spring-ts.article.v1",
  "articleId": "wealth.today.adult.mid.a",
  "category": "wealth",
  "period": "today",
  "audience": "adult",
  "band": "mid",
  "summary": "오늘 돈 관리는 크게 움직이기보다 정리하는 쪽이 이득이에요.",
  "hook": "지출 세 가지만 먼저 확인해요.",
  "body": [
    "오늘의 재물운은 큰 기회나 큰 위험 어느 쪽으로도 기울지 않은, 말하자면 평평한 길에 가까워요. 이런 날은 새로운 결정을 보태는 것보다 이미 굴러가고 있는 돈의 방향을 눈으로 확인할 때 이득이 커요. 통장을 스치듯 지나가는 고정 지출, 잊고 있던 구독료, 미뤄 둔 정산처럼 '이미 정해진 돈'을 오늘 한 번 들여다보면 이번 주 전체의 선택이 가벼워져요.",
    "사주에서 재물은 벌어들이는 힘과 붙잡아 두는 힘, 두 갈래로 읽어요. 오늘은 그 두 힘이 팽팽하게 맞서는 날이라, 들어오는 돈보다 새어 나가는 돈이 먼저 눈에 띄기 쉬워요. 다행히 균형이 크게 무너진 모양은 아니어서, 작은 확인 몇 번이면 충분히 중심이 잡혀요.",

  ],
```
