# 경우의 수 축소 전략 — 수식 정리 (전 차원 고려 + 군집·콜아웃)

> 모든 사주명리/성명학 차원을 **매핑에서는 전부** 고려하되, **저작은 등가 클래스만**. 근거 감사:
> [COVERAGE_AUDIT는 세션 산출]. 관련 [GENERATION_PIPELINE.md](./GENERATION_PIPELINE.md).

## 1. 전체 케이스 공간 (매핑 도메인)

모든 사람은 모든 축의 곱집합의 한 점으로 매핑된다:

```
F = C × P × A × B × Π(d ∈ D_saju) d × Π(m ∈ D_name) m
```

- C 분야(11) · P 기간 · A 오디언스 · B 밴드
- D_saju = { 강약, 격국, 용신, 십성주도, 신살집합, 궁위, 공망, 조후, … }
- D_name = { 자원오행보완(용신채움·기신역효과), 음령오행, 사격길흉, 수리, 음양, … }

|F|는 천문학적이나 **정보 천장**에 묶임: 정적 원국 8글자 = 518,400(성별 포함 1,036,800).
사주 파생축은 원국의 결정함수라 곱해도 천장 초과분은 구조적 0. **성명학의 수리·사격·음령은
원국의 함수가 아닌 독립 정보원**(획수·발음)이라 별도 자유도 — 이 부분만 천장 밖으로 실재 확장.

## 2. 축소 함수 — 세 역할 분할

각 차원 x를 발산 기준으로 배정한다:

```
role(x) = K  (클래스)  if  x를 바꾸면 조언의 방향/구조가 바뀐다
        = S  (슬롯)    if  x는 이름·단어만 바꾼다(오행명·대명사·계절어)
        = L  (콜아웃)  if  x는 희소·유무형이다(있을 때만 한 문장)
```

**저작 대상(클래스 수):**  `|K| = Π(x ∈ ClassDims) |x|`  — 천장 미만·저작 가능하게 설계.

**런타임 조립:**
```
Article(u) = canon[ κ(u) ] + Σ(s∈S) slot_s(u) + Σ(ℓ∈L) [ℓ present]·callout_ℓ(u)
```
κ: F → K 는 결정적 버킷 함수(강약 5→3, 격국 19→family 6, 용신→최종1오행 슬롯, 성별→민감분야flag…).

**유효성(valid) 두 조건:**
- **완전성**: κ 가 전함수 — 모든 사람이 정확히 한 클래스에.
- **건전성**: 한 클래스 내 모든 구성원이 canon+slot+callout로 *틀린 조언을 안 받음* ⇔ S축은 조언 방향 불변, L축은 가산적. (깨지면 군집화 무효.)

## 3. 차원 → 역할 최종 배정 (감사 반영)

| 역할 | 차원 | 카디널리티 |
|---|---|---|
| **K 클래스** | 분야 C | 11 |
| | 기간 P · 오디언스 A · 밴드 B | (기본 330 셀에 흡수) |
| | 강약(coarse) | 3 (약/중/강) |
| | 격국 family | 6 (인성·식상·재성·관성·비겁·특수) |
| | **nameEffect (자원오행 통합 2D)** | 4 (용신강보강·약보강·무관·**기신역효과**) |
| | 성별 (romance·family·career만) | ×2 |
| **S 슬롯** | 용신 오행명·일간명·계절/조후·성별대명사·음령오행 dominant | (문장 내 치환) |
| **L 콜아웃** | 신살(도화·역마·천을귀인·백호…)·사격 원형이정 특이길흉·궁위 특이·공망·12운성 | (있을 때만) |

> **감사 핵심 반영:** `이름보완 3`(matchCount≥1 이진)을 **nameEffect 4로 승격** — combinedDistribution의
> 부호(용신 채움 vs 기신 역효과)를 살려 "좋은 이름 vs 해로운 이름"을 클래스가 구분한다.

## 4. 클래스 수 (이 배정 기준)

- **실측(권위값) = `data/generation/manifest/index.json` = 21,060 클래스** (매니페스트 v2, generate-manifest.ts 실행 결과).
  - 카테고리별: 성별민감 3분야(romance/family/career) 각 2,700, 나머지 8분야 각 1,620.
  - 기본셀당 성인 = 강약3 × 격국6 × nameEffect4 = 72(성별민감은 ×2), 미성년 = 강약2 × nameEffect3 = 6.
- 아래 손계산(≈16,110)은 **v1 초기 추정치일 뿐** — 기본셀 분포(기간·오디언스·밴드)를 15/15로 단순화해 실제와 다르다.
  **권위값은 항상 index.json의 21,060.**
  - (참고 손계산) 성인 非성별 8,640 + 성인 성별민감 6,480 + 미성년 990 ≈ 16,110 (실제 기본셀 수와 불일치).

## 5. 실행 파이프라인 (§GENERATION_PIPELINE)

매니페스트 v2(클래스 열거) → prepare-batch(프롬프트) → **최대 병렬 OPUS 전문가 생성**(schema 강제)
→ validate(페어링·nameEffect 부호 정합) → `data/generated/` 저장. κ 함수는 selector 배관(후속).
