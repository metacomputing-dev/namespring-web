# 사주 보완 작명 정책

이 문서는 `spring-ts`의 자동 작명 후보 생성과 순위화가 지켜야 하는
해석 경계를 고정한다. 전통 명리·성명학의 한 학파 결론을 객관적 사실로
과장하지 않으며, 입력과 판단 근거가 부족할 때는 더 단정하지 않는다.

## 불변식

1. 사주 원국은 출생 정보와 시간 보정 정책으로만 정해진다. 이름을
   바꾸어도 원국은 바뀌지 않는다.
2. 이름마다 달라지는 것은 한글·한자 성명학 결과와 원국-이름 상호작용
   결과다.
3. 명식에 없거나 적은 오행은 진단 신호일 뿐, 곧바로 보충할 오행이
   아니다. 사주 보완 후보 생성에는 해석된 용신·희신 역할만 사용한다.
4. 기신·구신 또는 한 오행만을 이유로 합법적 한자 후보를 생성 전에
   제거하지 않는다. 성씨를 포함한 완성 이름을 계산한 뒤, 판단 확신도에
   맞추어 점수와 설명에 반영한다.
5. 사주 정보가 있는 자동 작명은 한자와 지정 음가가 확인된 후보만
   추천한다. 사주 정보가 없는 이름 전용 흐름에서만 순한글 작명을
   제공할 수 있다.

## 판단 강도

| 원국 근거 상태 | 후보 생성 정책 | 사용자 설명 |
| --- | --- | --- |
| `ready` | 용신·희신 자원오행을 우선 탐색하되 다른 오행도 보존 | 강한 선호 근거와 기신·구신 주의를 함께 표시 |
| `limited` — 용신 방법론 합의 충돌 | 용신·희신과 중립 후보를 교차 탐색 | 경쟁 오행과 낮은 합의도를 명시하고 단정 금지 |
| `limited` — 입력/분석 불완전 또는 종격 고위험 | 용신 기반 생성 선호를 중지 | 사주 보완 추천이 제한된 원인을 명시 |
| `unavailable` | 사주 보완 작명 결과를 만들지 않음 | 출생 정보 보완 또는 이름 전용 흐름 안내 |

원시 결핍·과다 오행은 위 표의 어느 상태에서도 생성 선호나 제외 목록으로
승격하지 않는다.

## 계산 순서

1. 출생지·표준시·경도 보정·균시차·야자시 정책을 확정하고 보정
   provenance를 남긴다.
2. 신강약·격국·조후와 여러 용신 판단법의 합의도를 계산한다.
3. 위 판단 강도에 따라 용신·희신 기반 탐색 순서를 정한다.
4. 대법원 인명용 한자와 해당 한자의 지정 음가를 확인하고, 뜻풀이와
   자원오행 데이터가 손상되지 않은 글자만 조합한다.
5. 성씨를 포함한 완성 이름을 대상으로 자원오행, 용신·희신·기신·구신
   상호작용, 음양·수리, 발음과 사용성 근거를 각각 계산한다.
6. 분석 원점수와 사용자에게 보여 주는 추천 순서를 구분한다. 표시 전용
   근거는 안전 탈락 조건이나 분석 점수인 것처럼 사용하지 않는다.

뜻풀이 문자열의 존재는 “뜻이 좋다”는 판정이 아니다. 이는 데이터
확인도일 뿐이며, 두 글자의 의미 결합과 실제 이름으로서의 자연스러움은
별도의 검토 근거가 있어야 한다.

## 출생순서·항렬·가족 제약

`장남·차남`은 아들끼리의 순서이고, `장녀·차녀`는 딸끼리의 순서다.
전체 자녀 중 몇째인지를 그대로 바꿔 부르는 말이 아니다.

일부 현대 작명 자료에는 장남·장녀에게만 권하거나 피한다는 한자
목록이 있다. 그러나 자료마다 목록이 다르고, 학술 검토에서도 널리
합의된 금칙으로 확인되지 않는다. 고전에서 확인되는
`伯(또는 孟)·仲·叔·季`는 주로 형제 순서를 나타내고 관례 뒤의
`字`에 사용한 용례다. 이를 오늘날 법적 이름의 운세 규칙으로 확대하지
않는다.

따라서 현재 자동 추천은 다음 원칙을 지킨다.

1. 출생순서만으로 한자를 반드시 포함하거나 제외하지 않는다.
2. 출생순서만으로 뜻 점수, 사주 보완 점수, 추천 순위를 바꾸지 않는다.
3. 이 기능을 위해 출생순서를 필수 개인정보로 수집하지 않는다.
4. 항렬자·돌림자는 출생순서가 아니라 같은 세대를 표시하는 별도
   가문 규칙이다. 사용자가 가문에서 확인한 글자와 위치를 직접
   제공할 때만 선택 제약으로 적용할 수 있으며, 성씨만 보고 추정하지
   않는다.
5. 향후 관련 설명을 제공하더라도 기본값이 꺼진 문화적 참고로만
   다루고, 불행·가족운 같은 결과를 단정하지 않는다.

법적 인명용 한자 여부와 작명학적 권장은 서로 다른 판단이다. 현행
인명용 한자 기준에는 출생순서에 따른 사용 제한이 없다.

## 실패 폐쇄 조건

- 보정을 켰지만 출생 지역 또는 좌표가 없음
- 사주 계산이 실패했거나 핵심 판단 축이 없음
- 한자-한글 음가가 공식 사용 범위와 맞지 않음
- 인명용 한자 여부 또는 원천 데이터 무결성을 확인할 수 없음
- 사용자가 한자를 요구한 사주 보완 작명에서 순한글 후보만 생성됨

이 경우 임의의 서울 좌표, 임의의 오행, 또는 중립 점수로 조용히
대체하지 않는다.

## 근거 범위

- 이재승, 「현대 성명학에서 한자선정법의 난제에 대한 해결적 고찰」은
  사주 보완 작명에서 무존재 오행이 아니라 용신 오행을 사용하고,
  성씨의 자원오행을 포함해 용희신의 상생을 고려해야 한다는 현대
  성명학의 한 연구 관점을 제시한다.
  <https://www.kci.go.kr/kciportal/landing/article.kci?arti_id=ART002615659>
- 사용할 수 있는 한자와 음가는 대법원 전자가족관계등록시스템의
  인명용 한자 기준을 따른다.
  <https://efamily.scourt.go.kr/cs/CsBltnWrtList.do?bltnbordId=0000010>
- 권익기·김만태, 「성명에서 이름자의 불용문자 고찰」과 권익기,
  「이름의 금기문자 고찰」은 불용문자 목록을 역사적으로 확립된
  보편 금칙으로 보기 어렵다는 학술 검토를 제시한다.
  <https://www.kci.go.kr/kciportal/landing/article.kci?arti_id=ART002335164>
  <https://www.kci.go.kr/kciportal/landing/article.kci?arti_id=ART002661459>
- 권익기, 「성명의 항렬자에 관한 고찰」은 항렬자를 가문의 같은
  세대를 표시하는 규칙으로 설명한다.
  <https://www.kci.go.kr/kciportal/landing/article.kci?arti_id=ART002290054>
- 《儀禮·士冠禮》의 `伯·仲·叔·季` 용례는 오늘날 본명 금칙이
  아니라 관례 뒤 `字`의 맥락으로 읽는다.
  <https://ctext.org/yili/shi-guan-li/zh>

성명학 관련 연구는 전통·현대 작명 관행을 설명하는 근거이지
자연과학적 예측 효능의 증명이 아니다. 대법원 자료는 법적 사용
가능성의 근거이며, 그 글자를 자동 추천해야 한다는 뜻은 아니다.
